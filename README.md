## 快速开始

1. 前往 [INSTALL.md](INSTALL.md) 查看逐套安装说明（整套安装或单个子 skill 安装）。
2. 把想要的系统目录复制到你的 Agent skills 目录即可，无需构建步骤。
3. 各系统的详细用法见其目录内的 `README.md` 与 `SKILL.md`。
