# 开场内容原型库（hook-prototypes）

> **rubric 教 AI 怎么打分；本文件教 AI 开场怎么推进**。消费方：oracle-seed（Phase 2A-2 起稿前选原型）、oracle-apprentice（Phase 3 拆稿时对照归类）、oracle-title（标题与开场一致性检查）。
> 与 starter-rubric 的 HP（hook power）维度解耦：HP 打"钩子强度"，本文件管"内容推进结构"——两层互补，不重复打分。

## 强开场四原则

强开场不是从"怎么写得燃"开始，而是从这四件事开始：

1. **起手证据**：先拿出一个具体东西、具体画面、具体现场或具体结果——不是形容词，是名词。
2. **观众卷入**：让观众意识到"这和我有关"或"这事我也好奇"。
3. **问题压缩**：把大主题压成一个很尖、很具体的问题——问得越窄，钩子越硬。
4. **内容承诺**：暗示后面真的有行动、测试、调查、对比或结果，不是空聊。

四条全命中 = HP 5 的结构基础；缺任何一条，文案再响也是弱钩子。

## 留存优先级（前 3 秒形成明确观看理由的手段，按优先级降序）

1. 具体物直接出现
2. 大结果前置
3. 真实现场、真实交易、真实行动
4. 观众熟悉现象切入
5. 价格、时间、人数、成本对照
6. 反常识现象
7. 特殊拍摄或视觉奇观
8. 真人测试或验证承诺

**慎用**：纯情绪、纯人物、纯失败危机开场——除非人物/情绪/危机本身能立刻变成可见证据（倒计时 / 明确后果 / 强观众关系 / 具体成本），否则不作为主开场入口。

## 10 个内容原型

> 生成开场前先判断选题适合哪些原型；一次主推 1 个，不混用。原型名只在拆解分析时使用，不写进面向观众的文案。

| # | 原型 | 结构 | 适用 | 留存手段 |
|---|---|---|---|---|
| 1 | 真实样本扩圈 | 具体样本 → 你也可能遇到 → 什么情况要关注 → 正片问题 | 健康 / 生活 / 社会观察 / 身体经验 | 起手证据 + 卷入 |
| 2 | 同题成本对照 | 同一任务 → A 花多少成本 → B 花多少 → 落差自现 | AI / 效率 / 技术替代 / 职业变化 / 商业模式 | 成本对照 + 承诺 |
| 3 | 大招前置 | 先展示最大结果 → 告诉观众这是真的 → 抛"为什么做到这步" | 重项目 / 大制作 / 极端实验 / 罕见资源 | 大结果前置 |
| 4 | 现场纪实破局 | 现场对话/交易/冲突 → 真实动机 → 这背后是什么 | 街头调查 / 骗局 / 商业套路 / 人物采访 | 真实现场 |
| 5 | 生活传说追查 | 你可能刷到过 → 多人同款问题 → 到底发生了什么 | 科普 / 科技 / 安全 / 网络传言 / 生活误区 | 熟悉现象 + 问题压缩 |
| 6 | 普通经验高规格拍摄 | 大家都玩过 → 但你从没这样看过 → 用专业方法拆开 | 运动 / 技能 / 科普实验 / 影像表达 | 视觉奇观 |
| 7 | 价格阶梯制造肉痛 | 便宜版 → 贵版 → 更夸张版 → 为什么还有人坚持 | 消费品 / 收藏 / 行业观察 | 成本对照 |
| 8 | 事件公布引出知识冲突 | 我们要做个改变 → 看似小变化 → 背后争了很多年 | 行业知识 / 技术标准 / 创作者幕后 | 反常识 + 冲突 |
| 9 | 虚拟灾难实体化 | 极端事件将至 → 撞上熟悉地点 → 这地方扛得住吗 | 天文 / 物理 / 灾难模拟 / 工程 / 脑洞科普 | 后果具象化 |
| 10 | 标题物直接验证 | 核心物摆出来 → 连续这样做会怎样 → 我们真测了 | 饮食 / 健康 / 测评 / 挑战 / 实验 | 具体物 + 验证承诺 |

## 与钩子 6 方向的关系

oracle-seed Phase 2A-2 的钩子 6 方向（预期违背 / 自我参照 / 信息缺口 / 冲突 / 身份反差 / 利益承诺）是**心理机制**——回答"观众为什么停下"；本文件的原型是**内容推进结构**——回答"第一秒到第十五秒放什么"。用法：先选原型（结构），再自检钩子方向（机制）——原型决定骨架，机制决定锐度，两层都要过。

## 拆解用法（oracle-apprentice）

拆对标稿的钩子时，把首段推进方式对照本表归类：命中哪个原型（或混合了哪两个）？起手证据是什么？问题压缩到多窄？归类结果写进知识卡片，并标注"该原型在用户自己的哪轨适用"。

## 负面清单（任何原型下都不要做）

- 不要以"今天我们来聊聊"开场——这是没有钩子的钩子
- 不要先解释背景再进入正题——背景不是证据
- 不要只写漂亮文案没有具体画面——形容词不留存
- 不要过早把结论说死——悬念死了观众就走
- 不要每条都强行高燃——选题调性决定节奏，克制也是钩子
