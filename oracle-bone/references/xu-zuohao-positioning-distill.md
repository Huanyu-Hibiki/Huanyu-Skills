## 1. 定位第一性：商业模式决定内容定位

《做号》第二章的核心链路（原创重述）：

```
你的商业模式（卖什么 / 卖给谁 / 客单价多高）
    ↓ 决定
你的用户画像（谁值得被你吸引）
    ↓ 决定
你的内容定位（做什么内容 / 什么风格 / 什么不要做）
    ↓ 决定
你的形象与平台策略（怎么呈现 / 去哪发）
```

**典型推理**（餐厅案例框架化 [做号·第二章]）：
- 高端餐厅 → 内容就应该是高端的；街头面店 → 内容就应该接地气
- 商业模式成熟，缺的只是流量 / 传播 / 新客 → 内容是获客手段，不是目的
- 结论：**不是"什么流量都要"，而是"什么客户该来"**

**反面模式** [做号·第三章]：一个账号若始终在推销自己的课程 / 服务 / 产品功效，讲自己有多好，就无法破圈——因为除了已产生购买意向的人，没人愿意看广告。账号从设计之初就错了。

## 2. 专业个人 IP 与娱乐网红的四大本质区别 [做号·第二章]

| 维度 | 娱乐网红 IP | 专业个人 / 创始人 IP |
|---|---|---|
| **商业模式** | 泛流量 → 卖给广告主（广告 / 带货 / 打赏） | 精准流量 → 自己的产品 / 服务变现 |
| **用户画像** | 流量最大公约数 = 大众化 | 特定人群、分众；**粉丝不求多而求精准** |
| **形象定位** | 情绪冲突、自黑、蹭热点 | 专业、审美、品质、温和、善意 |
| **成功路径** | 赛马制，千分之一概率 | 依托专业积累，成功概率可达三至五成 |

**精准粉的量化参照**（学员案例框架化 [做号·第二章]）：高客单定制生意，两千精准粉贡献年销售额千万级。用户质量越高，越不要求用户数量；高客单行业一年新增一个客户即可回本。

**推论**：不相干的人来关注，不是喜事，是**用户画像乱了**的信号。

## 3. 用户画像的推导方法

### 3.1 从商业模式反推（自上而下）[做号·第二/三章]

四个连续问题（原创设计，供采访使用）：
1. **你靠什么收钱？**（产品 / 服务 / 课程 / 咨询 / 品牌溢价）
2. **付钱给你的人是谁？**（行业 / 岗位 / 身份 / 消费力）
3. **他们在什么场景下会需要你？**（触发购买的时机与痛点）
4. **他们平时刷什么内容、停留在哪些平台？**（触达路径）

### 3.2 从竞品/对标账号验证（自外而内）

观察同类账号的评论区：留言者的职业构成、提问类型、购买意向表达——这是目标用户"活的样本"。

### 3.3 从自己账号回流验证（自下而上）[做号·第五章]

- **私域质量是定位准确度的最终检验**：进入私域的用户是否目标人群、是否有购买意向，最能反映账号定位准不准
- **评论区职业构成抽查**：点开互动者头像，判断其职业身份与画像的吻合度；若大量"莫名其妙的人"涌入，先查内容是否偏离（如被无关大 V 推荐导致的画像污染）
- **转化率链路诊断**：内容 → 私域 → 购买，每一环转化率高低都在验证账号设计与内容是否合理
- **前端功夫论**：信任是一切转化的基础，且运营不出来——功夫在前端的账号设计与内容制作，不在后端用户运营。前端内容不对，来的人不是目标用户，后端就是沙里淘金

## 4. 人设三原则 [做号·第四章 / 漏斗专题]

1. **内容型人设，而非卖货型人设**——账号打开不能是货架；先给价值再谈生意
2. **专家型人设，而非娱乐型人设**——专业性是专业 IP 与娱乐网红的本质区别；观众要的是信赖感
3. **真实型人设，而非虚假型人设**——从商业模式出发设计 ≠ 造假；不扮演完美，也不必曝光隐私

**形象的匹配律**：形象对应目标人群——目标是小众 / 分众 / 高净值人群，呈现就要有质感匹配；形象错配会让目标用户望而却步。

## 5. 平台策略 [做号·第五章]

- 平台选择取决于三要素：**内容形态 × 商业模式 × 用户画像**
- 起步策略：**多平台同步分发**，跑一段后看哪个平台表现 / 转化更好，升级为主力渠道
- **不为平台做特化版本**：多版本 = 工作量大 + 形象 / 风格混乱；低注意力流量本就不是高客单客户的来源
- 知识 / 教育 / 商业服务类（社交推荐占比高）可侧重强社交关系平台

## 6. 账号定位采访问卷（oracle-init Phase 2-4 使用，原创设计）

> 以下问题由上述框架派生，供 AI 采访用户时使用。**问法是本文原创，方法论归属徐沪生《做号》。**

### Phase 2 · 创作者档案（user-profile.md）

| # | 采访问题 | 推导目标 | 框架依据 |
|---|---|---|---|
| Q1 | 你靠什么收钱 / 打算靠什么收钱？客单价大概什么量级？ | 商业模式 | §1 定位第一性 |
| Q2 | 付钱给你的人是谁？描述一个最典型的客户 | 用户画像种子 | §3.1 |
| Q3 | 你比绝大多数人懂什么？（专业积累 / 行业年限 / 独特经历） | 专业优势 → 人设 | §2 成功路径 |
| Q4 | 有没有别人难以复制的资源或经历？ | 差异化 | §2 |
| Q5 | 你希望观众提起你时想到哪三个词？ | 形象定位 | §4 |
| Q6 | 哪些内容你绝对不做？（价值观 / 审美红线） | 漏斗外排除项 | 漏斗理论 |

### Phase 3 · 内容规划（content-plan.md）

| # | 采访问题 | 推导目标 |
|---|---|---|
| Q1 | 你的内容给谁看？这三类人分别是什么：会付钱的 / 潜在会付钱的 / 只是爱看的 | 漏斗三层人群 |
| Q2 | 如果分别给三类人做内容，你能做出哪些？（逐层盘点：破圈层 / 认知层 / 转化层） | 轨道数量判定 |
| Q3 | 各层内容你计划占多大比例？ | mix_ratio |
| Q4 | 每层内容"成功"长什么样？（播放 / 涨粉 / 同频评论 / 咨询 / 付费） | 各轨成功指标 |
| Q5 | 有没有与定位无关、但你想做的内容？（劝退测试：宠物 / 全民热点 / 个人生活） | 漏斗外内容排除 |

**判定规则**：
- 只答得上一层（常见：只有转化层或只有认知层）→ **单一内容**（1 轨）
- 能答上破圈层 + 转化层 → **双轨内容**（简化两层版，最常见起步）
- 三层都能支撑 → **三轨内容**（完整漏斗）
- 各轨占比由用户拍板，AI 只给参照（如双轨 40/60、三轨 4:3:3），跑满期数后 compass-retro 可提议修订

### Phase 4 · 用户画像（audience-profiles.md）

每轨回答四个子问题（对应 §3.1）：
1. 这轨内容想吸引的**核心受众**是谁？（是谁 / 怎么刷到 / 为什么停留）
2. 他们的痛点与需求是什么？他们在找什么？
3. 他们看到这轨内容会怎么互动？（评论倾向 / 什么话术触发私信咨询）
4. 从看到内容到信任到行动的路径是什么？

外加一个**一般关注**画像（非目标但会刷到的人群）：他们会怎么评价、会不会转发、可能提出什么质疑。
