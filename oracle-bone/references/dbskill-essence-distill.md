## 1. 定位与选题

| 框架/原则 | 核心 | 一句话用法 |
|---|---|---|
| **IP 价值创造五条件** | ①选题容量够长期更新（撑得起百条不重复）②价值已被市场验证 ③存在认知空白（同行没在语言层面讲透）④对核心概念有本质理解 ⑤能把复杂思想说简单 | init 定位自检：五条缺一不可持续 |
| **"泛直"内容论** | 好内容"不垂但直"——面向广泛人群做深入表达；垂=细分、直=深入，二者不必绑定；多平台同时跑通的都是泛直内容 | seed 选题：宁广而深，不窄而浅 |
| **先需求后产品** | 先有需求找产品=正常难度；先有产品找需求=地狱难度；内容先想清楚怎么拍，东西才值得做 | init Phase 2 商业模式审查 |
| **天崩开局识别** | 三种错误开局：抱着存量资源找生意 / 有粉不知卖啥 / 意外爆一条就仓促定型。0→1 先模仿不谈差异化 | init 预警 |
| **递归式内容生产** | 用自己的爆款数据做新内容（数据产出内容，内容再产出数据） | seed 选题来源之一 |
| **数据验证前置** | 低门槛平台（朋友圈/短文）先发收赞，收到赞再搬主平台 | seed 轻量验证 |
| **问题导向句式** | 负面框架胜正面框架："如何解决逻辑混乱" > "如何保持思维清晰"；归因外移卸自尊负担 | seed/title 句式选择 |
| **伪概念清除** | 慎用"赛道/刚需/精准流量/垂直"等未定义词——算法时代用户是动态向量，不是静态画像 | 全局语言纪律 |
| **业务=内容×商业模式** | 内容深度由商业模式决定；能摆脱流量焦虑的是商业模式不是涨粉 | compass-retro 诊断维度 |

## 2. 标题 · 封面 · 开头钩子

**三件套定流量**：封面+标题+开头决定一篇内容约 80% 流量。**标题是广告，正文是产品**——产品应围绕广告设计；套别人爆款标题=借别人的广告，没给自己的产品打广告。

**标题**：
- 标题负责"包装选题"（被点击），开头负责"展开选题"（被看完）——两者不可混用
- 爆款标题正确用法：识别钩子机制后为自己的选题**重写**，不逐字抄
- 标题找钩子法：平台搜选题关键词 → 只看千赞以上 → 其标题即被验证的钩子库
- 小红书标题 20 字上限（emoji/全角占 1 字、半角 0.5）；广告后台按 0.5 计可钻

**封面**：
- 图文平台（小红书）封面即一切——考核点击率；封面文字可直接复用被验证爆款原句（与标题相反）
- 换封面流程：找量级大的账号 → 追源头模板 → 全账号统一风格（"痛苦一次，轻松 N 次"）
- 封面图即人群筛选器：换图即换受众；低溢价感图吸低消费力人群
- 形式创新有红利：稀缺比例/形态（如竖屏 2:3）自带差异化
- 拍摄环境即背书：知识/商业类背景透出质感显著利于转化（底层是慕强）
- 白板/思维导图形式：口播看脸无法判断干货，白板一放自带"有真东西"的威慑（实测放大明显）

**开头钩子**：
- 死亡开头：任何形式的自我介绍/寒暄/日期报幕——第一句直接说事
- 平台指标倒推：抖音前 5s 完播（50% 及格、60% 上百万级）；视频号 3s；小红书 2s 跳出
- 高效模式：①结果前置（高光剪前 5 秒）②递归式（"上条爆了，今天拆"）③接高赞评论（评论区赞同票=市场验证的钩子）④痛点问句（警惕老套模板）
- 学霸开头法：平台搜提问式问题，高赞评论本身就是爆款开头
- 开头救不了选题错的内容——先确认"这个选题在该平台有人看"

## 3. 脚本与写作

| 原则 | 核心 |
|---|---|
| **知识博主两件事** | 把事情搞清楚 + 把事情说清楚，其余都是延伸 |
| **务实/务虚配比** | 聊具体操作必须务实到底（细节喂到嘴边）；聊方向认知要务虚拔高；混搭两头失 |
| **立场先于信息** | 只做"告知"型内容=工具人账号无人付费；赚钱的内容输出判断和立场 |
| **说服优先于信息** | 短视频核心技能是说服；情绪优先于信息 |
| **"翻译"论** | 自媒体本质是把中文翻译成中文——把"已觉易懂"再降一档门槛 |
| **结构化写作** | 用要素分块（markdown 式）写稿，天然适配短视频与 AI 改写 |
| **及格线** | 绝不能让观众产生"这还用你说"感——此线不过，技战术全废 |
| **长视频红线** | 超 5 分钟触发"一句话能说完"式差评；解法是压缩分层不是辩解 |
| **写稿三阶段** | 不写稿（无知）→ 写稿（学结构）→ 不写稿（知道何处该说何话） |
| **媒介不可直译** | 有流量的文字未必能翻译成有流量的视频；跨平台同理 |

## 4. 平台特性速查

| 平台 | 核心指标 | 用户心态 | 要点 |
|---|---|---|---|
| 抖音 | 前 5s 完播率 | 泛娱乐+泛学习；防御高（"敢教我赚钱就骂"） | 流量池最大；竖屏强开头 |
| 小红书 | 图文点击率；视频 2s 跳出 | 学习心智+焦虑浓度最高；共情场；要"不读书的读书感" | 图文封面为王；负面框架标题；开店即降权（平台视内容皆广告）；带货门槛 1000 粉 |
| 视频号 | 3s 完播+红心穿透（点赞即社交链再分发） | 中老年/下沉增量；未被充分洗牌 | 大众化宽选题；转化效率高涨粉慢 |
| B 站 | 社区投票+长视频逻辑 | 负面浓度最高 | 公域挂链转化可反超抖音；同步分发零成本 |
| 公众号 | 订阅制弱算法 | 沉淀与交付场 | 私域成交与知识库入口 |
| 通用 | — | — | 平台收两种税：广告费或内容税；让平台赚到钱的创作者混得更好；发布节奏"在线天数多、单日动作少" |

## 5. 对标方法论（learn-from / apprentice 弹药）

**五重过滤法（选对标）**：
1. **他真赚钱吗**——利润达你预期 10 倍量级（倍数差=安全边际，模仿必然失真，失真后仍超额才值得）；粉丝量不是钱
2. **你能看懂吗**——说清对方"获客→转化→交付→复购"完整链条
3. **你能模仿吗**——合理时间内能拿到资源执行；独家渠道/特殊资质型直接淘汰
4. **排除自我**——禁谈"不适合我/没兴趣"；追问具体哪一步做不了，说不出就是不想做
5. **不谈业务本质**——能干就干，不能干换下一个；禁用"赛道/行业"二词

**模仿纪律**：
- 只抄对标账号中**被验证的爆款**（对方数据平庸的内容也不抄）
- **抄逻辑不抄动作**：复制决策逻辑而非表面动作；目标是结果反超且看不出抄袭
- **像素级检查表**：产品价格/名称包装/获客平台/内容形式频率/标题封面/话术调性/交付促销，逐项对比，不一致处必须能解释
- **不做因果推断**：对标出镜你就出镜——"是否促进成交"是模仿三个月后才有资格梳理的信号
- Excel 三列法：锁定方向 → 列候选 → 按利润最高×执行门槛最低排序
- **AI 模仿文风的正路**：喂语料几乎必败；正确做法是把风格拆成上百个显式参数（词汇/句式/语气/认知立场），或"持续给负反馈→AI 整理成规则→收敛"迭代法
- 反被抄的应对：终极解法是商业模式壁垒，让抄袭者变成免费矩阵

**手艺层练习法（apprentice）**：
- 学文案对照法：爆款视频从第 15 秒开始看，先自己想"我会怎么写"，再对比原版；看懂百条破除恐惧
- 拆解见相关不见因果：99% 的拆解只看到相关性；真拆因果要理解心理机制而非表面参数

## 6. 转化与用户心理（who-for / open-source / simulate / init 画像弹药）

**用户画像反共识**：
- 画像=付费者共性，不是人口统计；买家之间性别/年龄/学历各不相同，唯一共同点是"做出了购买你的产品的决定"
- 画像靠交互数据反推（搜索/停留/点赞/收藏/完播），不靠想象
- 需求验证铁律："我想买"=不买，"我买了"才是想买——只认付款行为

**转化双引擎**：
- **幻想驱动**：人为"拥有之后我将成为谁"付费，不为功能付费——内容卖状态跃迁，产品是入场券
- **缺失补偿**：支付意愿与"偏离正常状态的恐惧"成正比——先量化用户正在失去什么，损失感比获得感催单
- **被服务需求**：买家要的常是"不被打扰地拿到结果"；高客单买的是"服务感"不是商品
- **回本心智**：只有"投资自己、能回本"的钱出得来——把产品重述为投资

**内容心理**：
- **认知段位定律**：认知高观众一段被关注；高十段被辱骂；高百段被嘲笑——有流量必被骂，与质量无关
- **拉黑筛选法**：内容的功能是把人群一分为二（粉丝或拉黑）；人畜无害的内容等于白发
- **看不懂的溢价**：不必人人看懂；听得出你厉害但听不懂的人付费意愿反而最高
- **获得感经济**：知识产品卖获得感不是知识；反效率的仪式感恰是价值
- 逃避正解悖论：多数人明知正解仍全力找绕路——内容要设计无法逃避的行动接口
- 行动等价定理："想做=不想做，正在做才是想做"——文案把"想/打算/准备"替换为已完成时态

**公开分享的底气（open-source 弹药）**：
- **易学守恒**：容易学会的藏着也赚不到钱，难学的公开反而增值——全量公开方法论不损失收入，公开本身是获客
- **阳谋原则**：一切赚钱相关的事公开也没用——愿意行动的人凤毛麟角
- 付费点落在产品不落在人：买家因人付费，但交易对象必须是物（工具/课程），否则把自己累死

## 7. 语言审查工具（no-ai-slop / 脚本打磨弹药）

**底层公理**：语言边界即思维边界；垃圾语言产生垃圾思维；想不清就说不清。

**模糊性检查清单**（文案体检）：
1. 未定义词扫描：普通人/执行力/干货/刚需/爆款/认知/垂直/精准流量——要么操作化定义要么弃用
2. 循环定义检测：用模糊词解释模糊词=把定义的债从 A 转给 B
3. 伪问题识别：先问主语是否被定义过；区分 question（疑问→有答案）与 problem（麻烦→只有内耗）
4. "本质上"禁令：滥用"XX 的本质是 XX"=认识论僭越
5. 模糊限定词清除："真正的XX会……"暴露没想清楚
6. 协作语言纪律：给人/AI 的指令禁用未量化主观词；"定义工程化"——要 80 分剧本就先定义每个名词与分数算法

**AI 味诊断（核心资产）**：
- **病根是权力关系**：AI 味不是修辞问题，是作者预设读者错误认知再推翻（先立蠢答案再秀优越）——修文案先修作者-读者权力站位
- **语气强度 vs 逻辑强度**：AI 爱用"请记住/真相是/不是A而是B/反问+感叹"——用祈使句制造紧迫感、以语气冒充逻辑；正解不是拉黑这些词，是补上经得起拆解的论证
- **"去 AI 味"是伪命题**：正确的问题是"这段文字像谁"——只要像一个具体的人就不像 AI；人味靠注入人格（人设/立场/具体经验），不靠删词
- **爹味检测**：反问句+"你难道不知道…"暗含"只有我对"
- **风格移植可复现路径**：上百个显式参数定义文风 → AI 把任意文本"翻译"成该风格（比喂语料有效得多）；提示词里禁止出现模板公式，只定义判断标准

**病句容忍度公式**：容忍度=语境冗余度×对象熟悉度×目的非正式性——三者任一下降，表达必须更精确。

## 8. 发布与运营（publish / pinned-comment / retro 弹药）

- **发布节奏**：平台偏好"在线天数多、单日动作少"；囤内容一天发完是大忌；手里常备 1-2 条成品调控节奏
- **投流=预支流速**：加热工具（dou+/薯条）不增加总量只提前释放；正确时机是自然流量停止增长之后；投任何东西前答得出"这个动作如何帮我赚钱"
- **互动杠杆**：小号评论区做示范引发跟风；干货密集的视频放一个可评论的实物道具；置顶评论本质是帮平台完成互动权重设计
- **老内容盘活**：流量差的视频只改标题和开头即可复活
- **长尾两法**：把流量层级冲到极高 / 占住搜索位
- **合规**：课程上架"赚钱/方法论"类卖点词不可写；敏感题材可做但措辞找对标学
- **私域校准**：引流是伪命题——用户加微信那一刻购买欲掉一半，转化动作尽量前置在公域；免费资料引来的私域是负债，应引"买家"入私域
- 曝光过百万进入非正常区：评论区管理成本陡增（疯/傻/喷三选一）

## 9. 复盘与诊断（retro / compass-retro / bump 弹药）

- **内容四层漏斗**：点击→点赞→关注→付费（或"看完即付费"）；走不到第四层的商业内容=电子垃圾——复盘按层找断裂
- **链路诊断**：失败很少是需求不存在，而是"需求→产品→内容→成交"四环逐环泄流——逐环检查找到断裂层再动手
- **单条爆款定律**：不追总量追单条爆量；爆的那条价值大于其余总和；发百条的意义是测出那一条
- **流量-收入脱钩**：内容含金量与流量无关联、与收入强相关；高转化内容与高流量内容不在同一条线上
- **越不赚钱涨粉越快**：涨粉与赚钱负相关是常态；粉丝量是毒药——不同量级处于不同流量池
- **量化资格线**：发满 100 条之前没资格讨论限流；没流量 99% 是内容不行
- **决策三律**：想不清楚→先干；干了很久没结果→停下想；产品摇摆→问是否真用户需求
- **焦虑的反面是具体**：拒绝讨论内耗话题，只给具体动作
- **复购是终极获客成本优化**：引流款目的是筛人，真转化率=复购率×频次
