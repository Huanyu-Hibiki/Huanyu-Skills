# Packaging Vocabulary（包装与动效规格语言）

> **被 oracle-apprentice（—visual 拆解）与 oracle-edit-plan（包装规格 / 成片验收）共用**——三方用同一套语言，retro 才能对比"拆了什么 → 计划了什么 → 成片做到了什么"。
> 方法论原理参考 hypit（修改版 Apache 2.0，仅学习原理，实现原创）；与 video-production-workflow 的执行侧词级时间戳天然对接（本语言只说"落在哪个词/句"，不写绝对秒数）。

## 1. 视觉系统（拆解与规划的单位）

**拆包装的单位不是镜头，是"视觉系统"**——活过一次剪辑切换的元素属于比镜头更长寿命的系统。把系统记一次，把它在时间上的变化标出来，而不是逐镜头流水账。

常见系统：字幕系统 / 贴纸与图标板 / 数据或排行榜板 / 转场体系 / B-roll 覆盖体系 / 音效体系 / 片头片尾结构。

## 2. 系统六元组（每个系统一份）

| 项 | 要回答的问题 |
|---|---|
| **内容与外观** | 它长什么样（字体气质/颜色/尺寸/材质），显示什么内容 |
| **空间关系** | 在画面哪里，和主体/字幕的遮挡与留白关系 |
| **入场** | 怎么出现的（路径/缩放/透明度/节奏/过冲与回弹），**在哪个词或动作上** |
| **活跃行为** | 存在期间干什么（跟随/高亮当前词/累积条目/呼吸） |
| **持续** | 存多久（一个短句/一段论述/整片），换内容时怎么替换 |
| **退场** | 怎么离开，为下一个想法腾出了什么空间 |

**绑定关系必填**：每个系统（及它的每次变化）标注它服务的**转写段落**（"transcript 第 N 段：<首几字>…"）——词锚，不是秒。换文案换配音，关系不变。

## 3. 动效四语义（描述每个动作的"为什么"）

| 语义 | 判断标准 |
|---|---|
| **入场抓注意** | 让观众看向新信息——但入场不是设计的全部 |
| **落定建状态** | 动完之后"定住的板"承载意义，定态往往比动画重要 |
| **替换保可读** | 内容 A 换成内容 B 时，变化本身要可辨认（不是无痕闪换） |
| **退场让位** | 为下一个想法清场——退场方式决定节奏感 |

**描述纪律**：动效名字只是起点（"弹入""滑出"）——规格要写**路径、缩放、透明度变化、节奏、过冲与回弹**。一个行为能解释许多帧，才算拆懂了；写不出"它服务哪句话"的动效 = 装饰，规格里标"装饰性"留待验收清退。

## 4. 声音四层（每层各有职能）

| 层 | 职能 | 规格要点 |
|---|---|---|
| 语音 | 主轴 | 任何画面切换不打断一句话中间（卡情绪重音除外） |
| 音乐 | 情绪底 | 进出场挂段落情绪；重拍可做切点参照 |
| 环境 | 真实感 | 跨切延续（房间底噪不随画面切换消失） |
| 音效 | 强调 | 挂**感知事件**（接触/到达/揭示/状态变化），不挂秒；全片密度克制 |

## 5. 词锚规格格式（packaging-notes 与 edit-plan 共用）

```markdown
## 系统：<字幕系统 / 贴纸板 / ...>
- 六元组：<逐项>
- 锚点：transcript 第 <N> 段（"<首几字>…"）<入场/替换/退场>
- 动效语义：<四语义之一>｜路径：<一句话>｜装饰性：<否/是>
```

**验收对照**（edit-plan accept）：成片中该动效是否落在预定的词/句上；每种字幕配置可读否；共享布局在内容替换后是否仍成立；装饰性动效是否挤占了信息动效。
