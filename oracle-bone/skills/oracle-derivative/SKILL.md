# /oracle-derivative — 内容复用工作流

**服务对象**：所有轨道。每期作品发布后 T+1 跑。

**为什么**：一期作品发完就归零 = 浪费。同一条内容的价值可拆成不同形态，触达不同平台的不同人群——视频抓推荐流，图文抓搜索流，短文抓深度阅读。

**方法论**：1-3-5 方法简化版（1 篇深度内容 → 3 个观点 → 精选形态分发）。不做全部 15 条衍生——每期只产出 **2 种形态**（多平台分发节奏下已够用）。

## 角色

**内容拆解编辑，不是文案搬运工**。

- 从定稿找**可独立成立的观点**——离开原作品也能看懂
- 图文 ≠ 简介改编；短文 ≠ 定稿全文。是独立创作

## 分发矩阵

```
一期作品
├── 主形态 → state.platforms 各平台        ← oracle-description 各平台文案
├── 图文   → 图文类平台（搜索流 + 收藏）    ← 本 skill 产出
└── 短文   → 长文类平台（深度阅读）         ← 本 skill 产出
```

**平台分工**：主形态抓推荐流靠钩子和完播；图文抓搜索流+收藏靠清单/检查卡/可截图内容；短文抓深度阅读靠展开原作一笔带过的细节。

## Workflow

### Phase 0: 读定稿 + 提取可独立成立的观点

1. 读作品定稿正文段（+ retro 阶段 `content-assets.md` 如有——复盘验证过的观点优先用）
2. 提取 1-3 个**可独立成立的观点**（标准：离开原作品也能看懂，可以继续展开举例；不是简介里的 summary 句）
3. 判断形态适配：

| 观点特征 | 适合形态 |
|---|---|
| 有反常识/有清单/有可截图内容 | 图文 |
| 有没展开的细节/故事 | 短文 |
| 同时满足 | 两种都做（观点同但展开角度不同） |

### Phase 1: 图文创作

**不是改编简介**——提取观点用图文语法重新创作：
- 第一句必须是钩子（反常识/痛点/共鸣）
- 正文 200-400 字短句为主
- **必须有可截图/可收藏内容**（清单/检查卡/对比图）——没有收藏价值的图文是废稿
- 结尾简短身份标签（不是营销 CTA）
- 标签 5-10 个
- 配图方向建议（风格/尺寸/核心视觉信息点）——具体配图工具由用户自选

### Phase 2: 短文创作

**不是复制定稿全文**——展开原作一笔带过、观众最想知道细节的那个点：
- 标题直接说核心（不标题党）
- 正文 400-800 字
- 展开 1 个没讲透的点（背景/过程/细节/方法）
- 结尾可引导回看原作
- 语气比口播更沉稳（长文平台读者年龄层偏大）

**选展开点标准**：原作只说 1-2 句但观众想了解更多 / 有具体操作步骤可写清 / 有真实经历细节可补。

### Phase 3: 落盘

```
<NNN>_<标题>/derivatives/
├── 图文.md
└── 短文.md
```

### Phase 4: 发布时机提示

```
✅ 衍生内容写完：
📄 derivatives/图文.md → 创作当天发（T+1）
📄 derivatives/短文.md → 当天或 T+2 发
💡 可先跑 oracle-no-ai-slop 检测再发
```

## Key Rules

1. **不是改编**。图文 ≠ 简介换格式；短文 ≠ 定稿改排版。提取观点独立创作
2. **每期只做 2 形态**。等节奏变慢再考虑增加
3. **图文必须有可截图内容**；**短文必须展开不重复**（读完发现和定稿 90% 重复 → 删掉重写）
4. **观点必须可独立成立**——依附原作上下文才能懂 = 不合格

## Refusals

- 「把定稿直接发长文平台」 → 拒绝。那是复制粘贴，不是衍生
- 「图文直接复制简介」 → 拒绝。简介是平台 SEO 文案不是独立内容
- 「一期拆 15 条」 → 拒绝。当前节奏只做 2 形态

## Integration

- 上游：oracle-publish（T+1 触发）+ oracle-retro 的 content-assets.md（验证过的观点优先）
- 去AI味：衍生内容可跑 oracle-no-ai-slop 检测
- **不进校准循环**（不 predict 不 retro）——独立发布；核心观点写回 content-assets.md 供后续 seed 用（标注"衍生已用"防重复）
- 时机：T+1 跑——发布当天让算法先推一波，第二天看初步反馈再定衍生角度（可根据观众评论调整切入点）
