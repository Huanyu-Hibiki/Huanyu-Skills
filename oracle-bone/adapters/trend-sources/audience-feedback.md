# audience-feedback — 受众反馈选题源

- **依赖**：无外部依赖；数据来自自己的已发作品
- **稳定性**：★★★★☆（依赖 retro 沉淀的数据 + 人工粘贴）
- **与外部热点源的区别**：不抓外部——从**自己受众的反馈**找选题。追问/抱怨/困惑是最准的需求信号。

## fetch 接口

1. 读 `.oracle-state.json` 各作品实绩数据（哪条互动高）
2. **问用户粘贴**：
   - 已发作品评论区的高赞/追问评论
   - 私信咨询内容（脱敏）
   - 粉丝群高频问题
3. 提取信号：用户追问（"那 X 怎么办"）/ 抱怨（"我们也遇到"）/ 困惑（"不懂为什么"）
4. 每个信号生成一条候选

## 输出

`source = "trend:audience-feedback"`；snapshot_text = 追问原文（脱敏）+ 来自哪条作品；note 标 "受众追问，优先级高"。

## 失败模式

- 用户没粘内容 → 空列表（正常，不算失败）
- retro 数据缺失 → 只用用户粘的部分

## 何时用

- 常规抓热点跑完后补一轮
- 转化轨选题枯竭时（受众追问 = 极刚痛点的直接证据，**优先级高于一切外部热点**）
