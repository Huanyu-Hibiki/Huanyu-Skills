# pulse-copywrite · 文案生成（沧溟体五段式）

把选题变成可直接复制粘贴发布的原创文案。

## 沧溟体五段式（默认爆款结构）

> 来源：沧溟老师的爆款内容方法论，经过实战验证。

```
① 痛点开头    → 复述用户真实痛苦，让他"这就是我"
② 反常识转折  → 否定错误归因（"不是因为你不努力"）
③ 案例证明    → 量化数据的前后对比（"调整前 500/小时，调整后一单 5 万"）
④ 方法论提炼  → 给出可执行的方法/框架/清单
⑤ 行动号召    → 低风险 CTA（领资料/私信/评论扣 1）
```

**如果用户给了对标爆款**：先拆它的结构（钩子/层次/号召），保留骨架、换内容——这是沧溟体对标的精髓。

## 何时触发

- 用户说"写文案""帮我写""小红书文案""沧溟体"
- pulse-topics 产出选题后，选一个来写

## 项目定制协议（条件执行）

如果《项目档案.md》登记了**定位协议文件**（品牌手册 / IP 对齐 / 内容红线，路径记在档案「定位协议」字段），所有 PulseHub 产物先读取该文件并服从其约束。PulseHub 只负责获客执行（关键词/选题/文案/CTA/私域承接），**不单独发明人设**——受众、母题、调性、产品路径、禁止事项一律以协议文件为准；协议与 PulseHub 默认结构冲突时，协议优先。

**Fallback**：档案未登记协议、或文件不存在 → 跳过本节，按《项目档案.md》自身的定位字段执行。

## 平台归属铁律（2026-08-05 实战沉淀）

**只写《项目档案.md》「主平台」字段声明的平台**（该字段由 `pulse-init` 初始化时确定）；字段为空 → 回 `pulse-init` 补跑 Round 3，或现场确认一次并把结论写回档案再动笔。

| 规则 | 内容 |
|---|---|
| **主平台**（原创产出） | 档案声明的目标平台（如图文平台 = 文字 + 配图） |
| **分发渠道**（只搬运不重写） | 直接复用主平台内容，按渠道裁剪适配 |
| **不写未声明的平台** | 其他内容线（长文/长视频/问答）若由别的流程或 skill 负责，登记在档案「内容线分工」里，PulseHub 不越界 |
| **图文 = 文字 + 配图** | 只交文字 = 未完成（规格与流程见下节「"图文"= 文字 + 图片」） |
| **视频 B 轨联动** | 选题适合视频时，在文案末尾附「视频选题参考」表（只列选题不写脚本），供档案登记的视频流程/skill 参考 |

## 前置（必读）

1. **读 `个人风格.md`** ⭐ —— 人称、语气、句长、口头禅、禁用词
2. **读 `人群语料库.md`** ⭐ —— 用真实用户原话（买点语言），不用 AI 编的
3. **读 `爆款素材库.md`** —— 引用已验证的钩子公式
4. **读 `项目档案.md`** —— 产品信息 + 卖点 + 关键词

**Fallback（前置文件缺失时）**：`个人风格.md` 还是模板 → 先问用户要 2-3 段旧文现场提炼，用户没有 → 在产出里标注「文风未对齐，发布前必跑 pulse-humanize」；`人群语料库.md` 还是模板 → 先跑 `pulse-insight`，只有用户明确说"先写再说"才允许用 `[待补充真实原话]` 占位继续。

## "图文"= 文字 + 图片（2026-08-06 实战沉淀）

**"图文"字面 = 图片 + 文字**，不能只给文字稿。

交付一篇图文笔记必须包含：
1. 文字稿（沧溟体五段式正文 + 标签）
2. **配图**（用档案登记的配图工具生成 3:4 社交卡片图；未登记 → 按规格输出每页文字与视觉要点，提示用户接配图流程）

只交付文字 = **未完成**。写完文字稿后必须接配图流程，不是等用户提醒。

配图流程详见 `references/image-generation-workflow.md`。

## 核心原则

### 1. 买点语言 > 卖点语言

文案里每句话尽量像**买家内心独白**，而不是产品说明书。

```
✗ 卖点语言："[产品名] 支持智能审查"
✓ 买点语言："[客户名] 怕条款责任边界没看出来，后面项目背锅"
```

### 2. 4 步心理闭环（少一步都不成交）

```
① 看见自己的痛苦 + 沉没成本
② 认可你的专业判断（反差纠错）
③ 看见他人拿到的正向结果（量化数据更好）
④ 知道下一步怎么找你付费（低风险 CTA）
```

文案里别只讲利他/只立人设——网上好人/干货博主很多，用户不会单纯为此付费。

### 3. B 轨转化型三段式

每篇必须套"**问题 → 解法 → 成果**"结构。冷启动期（≤30 天）只写转化型。

```
7 天 7 条转化型 ≥ 30 天 50 条流量型
```

流量型（日常/热点/段子）默认不写。

### 4. 预期管理（5.0 核心）

不要只晒案例/讲干货/证明专业。前段替用户校准预期：

- **适合谁** / **不适合谁**
- **能做到什么** / **做不到什么**

边界越清楚，越能筛出高质量客户。

### 5. 文案服务 L4 自有产品

不要写成平台流量分成/品牌广告/工具测评。每篇都要自然回到自己的产品/服务。

## 工作流

### Step 1 · 确认参数

| 参数 | 选项 |
|------|------|
| **平台** | 读档案**「主平台」**字段（init 时已确定）。分发渠道=直接搬运主平台内容，不重写。字段为空 → 回 init 补或现场确认后写回。视频脚本→`pulse-script`；档案「内容线分工」登记的其他内容线不归本 skill。 |
| **字数** | 图文平台 200-500 / 深度长文 1500-3000（按主平台惯例） |
| **目的** | 种草 / 教育 / 转化 / 引流 |
| **对标爆款** | 用户提供了？→ 拆结构；没提供？→ 用沧溟体五段式 |

### Step 2 · 生成 3 篇原创（沧溟体五段式）

每篇严格走 5 段：

```
【标题】（不含标点，≤ 20 字，含数字或情绪点）

① 痛点开头（2-3 句）
   [用人群语料库的真实原话]
   [复述用户的沉没成本：时间/钱/精力]
   标注：[此处可加你的真实经历]

② 反常识转折（1-2 句）
   "不是因为你不够努力，是因为 X"
   [否定用户的错误归因]

③ 案例证明（2-3 句）
   "调整前：[量化数据]。调整后：[量化数据]"
   [用真实案例，不编造]

④ 方法论提炼（3-5 句）
   [给出可执行的框架/清单/步骤]
   [买点语言：像买家在想什么]

⑤ 行动号召（1-2 句）
   [低风险 CTA：领资料/私信/评论扣 1]
   [不提"我看到你的评论"]
```

### Step 3 · 平台适配

| 平台 | 特殊处理 |
|------|---------|
| **主平台**（读档案「主平台」字段；常见如小红书图文） | 标题 ≤ 20 字带情绪；emoji 适度（按个人风格）；话题标签 5-8 个；**必须配图**（3:4 卡片图，工具与规格见「"图文"= 文字 + 图片」节） |

**分发搬运**（不重写，直接用主平台图文）：
| 渠道 | 说明 |
|---|---|
| 同生态图文渠道（如抖音图文、B站图文/动态） | 直接复用主平台图片，裁剪适配 |

### Step 4 · 输出格式（每篇）

```markdown
## 文案 N：[标题]

- **标题**：[≤ 20 字，含数字或情绪]
- **封面建议**：[颜色/元素/排版方向]
- **正文**：[可直接复制粘贴，带 emoji，分段清晰]
- **话题标签**：[5-8 个：核心词 + 长尾词 + 流量词]
- **变现钩子**：[一句话：如何引导到产品/引流品]
- **产品资产指向**：[这篇沉淀到哪个产品/服务/工具]
- **预期管理边界**：[适合谁/不适合谁/能交付/不能交付]
- **4 步闭环标注**：
  - ① 痛点（第 X 段）
  - ② 判断（第 X 段）
  - ③ 案例（第 X 段）
  - ④ CTA（第 X 段）
- **留白标注**：[此处可加你的真实经历/口头禅]
```

### Step 5 · 自检（发布前必跑）

1. ❌ 有 `个人风格.md` 的禁用词？
2. ❌ 有 AI 腔（"值得注意的是""不仅...而且..."）？
3. ❌ 有编造的用户原话？
4. ❌ 4 步闭环缺步？（标注"需补步"）
5. ❌ 没有预期管理边界？（标注"需补边界"）
6. ❌ 没有产品资产指向？（标注"需重写"）
7. ✅ 有真实用户语言？
8. ✅ 文风像用户本人？

**🔴 CHECKPOINT · 🛑 发布门**：自检 8 条全过 → 提醒用户跑 `pulse-humanize` 做专业去 AI 味，**humanize 通过 + 用户补完留白真实经历后才算可发布**。任一条 ❌ → 回 Step 2 重写，不带病发布。

## 人 × 数字员工分工

- **人**：选版本、加个人真实经历（按 `[ ]` 提示填）、确认发布、**发布后回填数据**
- **数字员工**：沧溟体五段式生成 3 版本、平台适配、自检、4 步闭环标注

## 沉淀动作

- 用户采纳某篇后，把**结构公式**追加到 `爆款素材库.md`（若新颖）
- 用户反复用了某表达 → 回填到 `个人风格.md` 的"高频金句"段

## 输出

```
✅ 3 篇沧溟体文案已生成
   每篇含：五段式结构 + 4 步闭环 + 预期管理 + 产品资产指向 + 留白标注

⚠️ 发布前必跑 pulse-humanize（"去 AI 味"）——见 Step 5 发布门
⚠️ 按留白标注补充真实经历（AI 编的经历一眼假）

👉 发布后回填 数据反馈.md（曝光/点赞/评论数据）
👉 视频选题说"写脚本" → pulse-script
```

## 注意

- **沧溟体五段式是默认结构**，不是唯一结构——用户给了对标爆款时优先拆对标
- **绝不编造用户原话**——`人群语料库.md` 没有合适的就标 `[待补充真实原话]`
- **绝不编造案例数据**——标 `[待确认数据]`
- **纯干货会吸引白嫖党**——转化型文案必须加入案例研究或前后对比
