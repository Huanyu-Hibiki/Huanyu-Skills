# pulse-topics · 爆款选题（四维挖掘法）

从"产品视角"切换到"用户愿意点开什么"。

## 四维挖掘法

> 经过实战验证的选题生成框架——30 个选题覆盖 4 个角度。

| 维度 | 数量 | 核心逻辑 | 思路 |
|------|------|---------|------|
| **A. 用户需求挖掘** | 10 | 用户已经在问的问题 | 基于痛点 + 搜索行为 |
| **B. 竞品差异化** | 10 | 别人讲"怎么做"，你讲"**为什么失败**" | 别人讲结果，你讲过程 |
| **C. 热点嫁接** | 5 | 结合当下热点/节日/行业事件 | 热点 × 你的赛道 |
| **D. 转化反推** | 5 | 从产品卖点出发，设计认知→兴趣→决策路径 | 直接引导付费 |

## 何时触发

- 用户说"选题""做什么内容""不知道发什么""四维挖掘"
- 关键词矩阵完成后

## 项目定制协议（条件执行）

如果《项目档案.md》登记了**定位协议文件**（品牌手册 / IP 对齐 / 内容红线，路径记在档案「定位协议」字段），所有 PulseHub 产物先读取该文件并服从其约束。PulseHub 只负责获客执行（关键词/选题/文案/CTA/私域承接），**不单独发明人设**——受众、母题、调性、产品路径、禁止事项一律以协议文件为准；协议与 PulseHub 默认结构冲突时，协议优先。

**Fallback**：档案未登记协议、或文件不存在 → 跳过本节，按《项目档案.md》自身的定位字段执行。

## 前置

1. **读 `项目档案.md`** 取关键词矩阵 + 目标平台 + 对标账号
2. **读 `人群语料库.md`**（pulse-insight 产出）——选题要对应用户真实痛点
3. **读 `爆款素材库.md`** ——复用已验证的爆款公式

**Fallback（前置缺失分级处理）**：项目档案缺失 → 🛑 先跑 `pulse-init`；语料库还是模板态 → 提示先跑 `pulse-insight`，用户说"先出选题" → 照常生成但每个选题的痛点列标 `[待语料校准]`；**爆款素材库为空是正常态**（首次本来就是空的），直接跳过复用。

## 工作流

### Step 1 · 营销视角过滤

对每个候选选题，先问：
- **给谁看的**？（具体到子群体）
- **看完会做什么**？（点赞/收藏/评论/私信/分享）
- **KPI 是什么**？（曝光 vs 转化）

### Step 2 · 四维生成 30 个选题

**A. 用户需求挖掘（10 个）**

基于 `人群语料库.md` 的痛点和搜索行为：
```
示例：
- "工程合同里最容易被忽略的 3 个条款"
- "造价员算错一个小数点被扣 80 万"
- "甲方说'不专业'的时候，你在亏什么"
```

**B. 竞品差异化（10 个）**

核心思路："别人讲怎么做，你讲为什么失败"
```
示例：
- "为什么 9 家公司换了 AI 工具又换回来了"
- "别再用 Excel 算报价了——3 个血淋淋的案例"
- "同行不会告诉你的 XX 真相"
```

**C. 热点嫁接（5 个）**

结合当下热点 × 你的赛道：
```
示例：
- "XX 新规出台，90% 的人不知道影响"
- "[行业事件] 给我们的 3 个启示"
```

**D. 转化反推（5 个）**

从产品卖点出发，设计认知→兴趣→决策路径：
```
示例：
- "免费送 XX 自查清单（评论区扣 1）"
- "我们帮 XX 公司 3 个月降本 50%——怎么做到的"
```

### Step 3 · 每个选题标注

| 字段 | 内容 |
|------|------|
| **序号** | 1-30 |
| **选题** | 具体标题草稿 |
| **维度** | A/B/C/D |
| **平台** | 读档案「主平台」字段（init 时确定）；字段为空 → 回 init 补或现场确认后写回 |
| **内容形式** | 按主平台惯例（图文 = 文字 + 配图，配图工具按档案登记） |
| **变现钩子** | 评论区互动 / 私信引导 / 关注 / 领资料 |

**注意**：选题表里只出现档案声明的主平台与分发渠道的形式；档案「内容线分工」登记的其他内容线（如长文、长视频、问答专栏）由别的流程/skill 负责，**不进本选题表**。

**输出示例**：

| # | 选题 | 维度 | 平台 | 形式 | 变现钩子 |
|---|------|------|------|------|---------|
| 1 | 工程合同 3 个致命条款，90% 的人没看过 | A | 小红书 | 图文 | 评论区扣 1 领自查清单 |
| 11 | 为什么 9 家公司换了 AI 又换回来了 | B | 小红书 | 图文 | 私信领对比表 |
| 21 | XX 新规出台，你的合同合规吗？ | C | 小红书 | 图文 | 关注领解读 PDF |
| 26 | 免费：3 分钟测试你的合同风险分 | D | 小红书 | 图文 | 私信领工具 |

### Step 4 · 自动发现热门参考（PulseHub 工具集成）

```bash
# 发现当前热门（从 PulseHub 仓库根执行；_shared/ 是共享脚本目录）
bash _shared/scripts/shell/rsshub-fetch.sh "/bilibili/popular/all"
bash _shared/scripts/shell/rsshub-fetch.sh "/zhihu/hotlist"

# 标准化 + 评分（需要 _core/pulse-resolve 的 pnpm 环境）
pnpm --filter pulse-resolve exec tsx src/cli.ts {URLs}
```

**Fallback**：RSSHub 不可用 → 跳过自动发现，Step 2 四维生成不受影响（它不依赖热门数据）；`pnpm` 环境缺失 → 跳过 resolve/enrich，直接按 URL 人工筛（仅少了评分排序，不阻塞选题产出）。

用 `pulse-enrich` 评分找高互动帖子，**拆解结构**（不抄内容，学骨架）。

### Step 5 · 拆解后更新爆款素材库

对发现的每个高价值爆款，拆出钩子公式 → 写入 `爆款素材库.md`。

### Step 6 · 更新索引

更新 `项目档案.md` 累积产出索引。

## 人 × 数字员工分工

- **人**：从 30 个里挑 3-5 个今天执行的
- **数字员工**：四维生成 30 个、热门发现、结构拆解

```
✅ 选题库已生成（四维 × 30 个）
   - A 用户需求：10
   - B 竞品差异化：10
   - C 热点嫁接：5
   - D 转化反推：5
✅ 爆款素材库.md 已更新
✅ 项目档案.md 索引已更新

👉 建议下一步：
   - 写文案 → pulse-copywrite（"沧溟体五段式"）
   - 写脚本 → pulse-script（"沧溟体逐字稿"）
   - 发布前补转化闭环：引流品 + 私信承接话术（pulse-private）
```

## 🔴 CHECKPOINT · 发布前闭环检查

第一条内容产出后，**🛑 STOP：不要默认继续批量写第 2 条**。先检查 CTA 是否能接住：

1. 如果内容里写“评论/私信领清单”，必须先生成真实可发的引流品（Markdown / PDF / 飞书表格均可）。
2. 必须准备私信承接话术：用户评论后怎么回、发清单时怎么问需求、不同场景如何转试用。
3. 项目档案索引要记录内容产物与承接资产。
4. 如果用户有独立视频创作链路，pulse-script 产出的脚本可作为参考，不强制作为拍摄主链路；PulseHub 此阶段主要负责“选题 → 痛点 → 文案 → CTA → 承接资产”。

## 注意（含红线）

- **30 个不是最终方案**——AI 给候选，人挑 3-5 个（AI 不代挑）
- **B 维度（竞品差异化）最值钱**——"别人讲怎么做，你讲为什么失败"
- **D 类（转化型）不超过 1/6**——全转化型会掉粉
- **选题要对应痛点**——没对应痛点的选题是自嗨
- **不写档案未声明内容线的形式**——长文/长视频等由「内容线分工」登记的流程负责
