# pulse-script · 视频脚本（沧溟体逐字稿）

把选题变成可直接拍摄的脚本，精确到**每个字的口播 + 每个镜头的画面**。

## 沧溟体逐字稿

> 核心产出：不是大纲，是**每个字都写出来**的逐字稿，带语气标注。

```
语气标注系统：
  ↑     = 升调（疑问/惊讶）
  ↓     = 降调（肯定/沉重）
  …     = 短停顿（0.5s）
  ——    = 长停顿（1-2s）
  【重】 = 重音
  【快】 = 加速
  【慢】 = 放慢
  (笑)  = 情绪标注
  (叹)  = 情绪标注
  (认)  = 认真/严肃
```

## 何时触发

- 用户说"视频脚本""沧溟体逐字稿""口播稿""拍视频"
- pulse-topics 选定视频类选题后
- pulse-copywrite 产出文案后，想改编成视频版

## 项目定制协议（条件执行）

如果《项目档案.md》登记了**定位协议文件**（品牌手册 / IP 对齐 / 内容红线，路径记在档案「定位协议」字段），所有 PulseHub 产物先读取该文件并服从其约束。PulseHub 只负责获客执行（关键词/选题/文案/CTA/私域承接），**不单独发明人设**——受众、母题、调性、产品路径、禁止事项一律以协议文件为准；协议与 PulseHub 默认结构冲突时，协议优先。

**Fallback**：档案未登记协议、或文件不存在 → 跳过本节，按《项目档案.md》自身的定位字段执行。

## 前置

1. **读 `个人风格.md`** ⭐ —— 口播语气、句长、口头禅、禁用词
2. **读 `人群语料库.md`** —— 视频内容要对应用户痛点（买点语言）
3. **读 `爆款素材库.md`** —— 引用已验证的视频钩子公式
4. **读 `项目档案.md`** —— 产品信息 + 客单价 + 变现方式

**Fallback（前置缺失）**：项目档案缺失 → 🛑 先跑 `pulse-init`；个人风格是模板态 → 问用户要 2-3 段旧口播/旧文案现场提炼，要不到 → 逐字稿照常产出但标 `[文风未对齐]`；语料库是模板态 → 痛点段标 `[待语料校准]`，不编造原话。

## 分支选择

### 分支 A：用户自带工作流

如果用户在 `项目档案.md` 配置了自带视频创作流程：
1. 不另起炉灶，按用户原有流程的格式产出
2. 只补缺的环节（如有拍摄没有钩子设计）
3. 告诉用户"按你原有流程格式生成，直接喂进去"

### 分支 B：默认本 skill 流程（沧溟体）

按下面的结构 + 输出执行。

## 两种视频结构

### 结构 1：标准短视频（15-60s）

适用：小红书视频 / 抖音 / 视频号

```
[0-3s]   钩子    痛点问句 / 反差画面 / 数字冲击
[3-15s]  痛点    用人群语料库的真实痛点（买点语言）
[15-30s] 方案    核心卖点 + 反常识转折
[30-45s] 案例    量化数据的前后对比
[45-60s] CTA     低风险行动号召（领资料/私信/评论）
```

### 结构 2：高客单获客视频（3-7min）

适用：B站长视频 / 视频号 / 抖音知识型

```
0:00-0:30   钩子 + 看见痛苦 + 冰山下问题
            必含身份锚点："我是 XX，一直在做 XX"
            复述用户沉没成本（时间/钱/精力）
            开口直接复述客户的"冰山下真实问题"
            不是他嘴上说的"账号没流量"
            是他真被困住的"变现路径没理清"
            观众看到你"比我还懂我"就停下来

0:30-1:30   反差纠错：否定用户的错误归因
            "不是缺流量/不是不够努力/不是不会拍，是 X"
            建立专业判断

1:30-3:30   真实案例：客户前后对比
            少讲个人履历，多讲客户改变
            "调整前单小时 500，调整后一单 5 万"
            第一视角/现场拍摄/真实场景比口播可信

3:30-5:30   持续损失 + 紧迫感
            "当下不解决，每天在浪费什么？"
            流量/客户/时间/合规风险

5:30-7:00   低风险 CTA
            私信场景、领清单、进群、自查
            清晰告诉用户"下一步怎么找你付费"
```

**高客单禁忌**：一开场自我介绍、堆产品功能、追泛流量情绪、给"全套攻略"。高客单用户买的是**确定性**，不是热闹。

## 工作流

### Step 1 · 确认脚本参数

| 参数 | 选项 |
|------|------|
| **平台** | 默认读档案「主平台」字段（init 时确定）的对应视频形态；无档案/空缺 → 抖音（竖屏）/ 视频号 / B站（横屏）让用户选 |
| **时长** | 15s / 30s / 60s / 3min / 7min |
| **结构** | 标准短视频 / 高客单获客 |
| **风格** | 纯口播 / 口播+B-roll / 演示+旁白 / 剧情 |
| **出镜人** | 有 / 无 |

**Fallback（用户不给参数时）**：用户只说"写个脚本"不选参数 → 默认「抖音 / 30s / 标准短视频 / 纯口播 / 有出镜」并在产出开头注明默认值，用户可改。**不要**连环追问 5 个参数阻塞流程。

### Step 2 · 写沧溟体逐字稿

按沧溟体五段式写口播稿，**精确到每个字 + 语气标注**。

示例（30 秒标准版）：

```
【重】你还在用 Excel 算报价？↑

（停顿 0.5s）

上周有个造价员…算错一个小数点——
甲方直接扣了 80 万。【慢】

（认）不是你不够仔细。
是你用的工具——就该被淘汰。

我换了 AI 审计工具之后——
同样的清单…3 分钟跑完，零误差。（笑）

评论区扣 1——发你自查清单。↓
```

**字数控制**：
- 15s → 35-45 字
- 30s → 75-90 字
- 60s → 150-180 字
- 3min → 450-540 字
- 7min → 1050-1260 字

**口播铁律**：
- 短句为主（一口气读完 ≤ 15 字）
- 口语化（"咱们"不是"我们"）
- 有节奏（长短句交替）
- 有停顿标记（`…` / `——`）
- 禁用 `个人风格.md` 的禁用词
- 不编造数据——标 `[待确认数据]`

### Step 3 · 画面分镜（每 5 秒一镜）

| 时间 | 镜头 | 画面内容 | 口播对应 | 字幕 |
|------|------|---------|---------|------|
| 0-5s | 特写 | Excel 报价表格 + 红色错误标记 | "你还在用 Excel..." | 【Excel 算报价？】 |
| 5-10s | 中景 | 出镜人摇头 + 合同特写 | "算错一个小数点..." | 【扣了 80 万】 |
| 10-15s | 近景 | 出镜人认真看镜头 | "不是你不够仔细..." | 【工具该换了】 |
| 15-20s | 录屏 | AI 工具操作界面 | "我换了 AI 工具..." | 【3 分钟 / 零误差】 |
| 20-25s | 特写 | 手机评论区打"1" | "评论区扣 1..." | 【扣 1 领清单】 |
| 25-30s | 全景 | 出镜人微笑 + 产品 LOGO | (收尾) | 【关注获取更多】 |

### Step 4 · 完整输出（7 项）

```markdown
# 视频脚本 — [选题名]

## 1. 口播稿（沧溟体逐字稿）

[完整逐字稿，含语气标注↑↓…——【重】【快】【慢】(情绪)]

## 2. 画面分镜

[每 5 秒一镜的分镜表]

## 3. 字幕建议
- 关键数字高亮（颜色/字号/出现时机）
- 痛点词放大

## 4. BGM 建议
- 情绪基调 + 参考曲风（不推具体歌曲避免版权）

## 5. 封面帧建议
- 选哪一帧 + 上面压什么字

## 6. 产品资产指向
- 这条视频沉淀到哪个产品/服务/工具
- 若只是泛流量 → 标"需重写"

## 7. 预期管理段落
- 前 30 秒如何说明适合/不适合、能做/不能做
- 若没有 → 标"需补边界"
```

## 人 × 数字员工分工

- **人**：按脚本拍摄、剪辑、出镜、加自己的口头禅、最终修改口播
- **数字员工**：沧溟体逐字稿、分镜表、字幕/BGM/封面建议、产品资产指向

**🔴 CHECKPOINT · 🛑 拍摄门**：逐字稿 + 分镜表产出后，先让用户**朗读一遍口播稿**——拗口/超时/不像本人说话的地方当场改，改完再进拍摄。口播稿没过用户嘴 ≠ 可拍摄。

## 输出

```
✅ 视频脚本已生成
   - 时长：[X]s/min
   - 结构：[沧溟体五段式 / 高客单需求旅程]
   - 口播字数：[X] 字
   - 分镜数：[X] 个
   ✅ 沧溟体逐字稿（含语气标注）
   ✅ 分镜表
   ✅ 字幕/BGM/封面建议
   ✅ 产品资产指向
   ✅ 预期管理段落

⚠️ 拍摄前建议跑 pulse-humanize（"去 AI 味"）检查口播

👉 发布后回填 数据反馈.md（播放/点赞/评论数据）
```

## 注意

- **逐字稿不是大纲**——每个字都要写出来，包括语气标注
- **口播必须能一口气读完**——每句 ≤ 15 字
- **不编造数据**——标 `[待确认数据]`
- **B-roll 建议要具体**——不是"拍点产品镜头"，是"手机正面 45 度俯拍展示 XX 功能"
- **产品演示 > 纯口播**——高客单视频至少 2 次产品演示（Excalidraw/录屏/实操）
