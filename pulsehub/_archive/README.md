# Project Archive — 项目大脑

> **项目大脑**是 PulseHub 获客系统的共享记忆层。所有 skill 通过这里交换上下文、沉淀资产、积累反馈。**越用越聪明**。

## 工作方式

1. `pulse-init` 首次运行时，把这里的 6 个模板文件复制到 `~/.pulsehub/archive/<项目名>/`
2. 后续每个 skill 读取需要的文件，产出后追加/更新
3. `项目档案.md` 是主入口（Hub），维护一张"累积产出索引"表，链接到其他 5 个文件

## 6 个文件

| 文件 | 角色 | 谁写入 | 谁读取 |
|------|------|--------|--------|
| `项目档案.md` | **Hub**：基本信息 + 平台账号 + 累积产出索引 | pulse-init | 所有 skill |
| `人群语料库.md` ⭐ | 真实用户原话 / 痛点词典 / 拒绝理由 | pulse-insight, pulse-leads | 所有写文案的 skill |
| `爆款素材库.md` | 拆过的爆款结构 / 钩子公式 / 对标账号 | pulse-topics | pulse-copywrite, pulse-script |
| `话术资产.md` | 欢迎 / 培育 / 成交 / 异议处理话术（带效果标签） | pulse-private, pulse-leads | pulse-leads, pulse-copywrite |
| `数据反馈.md` ⭐ | 真实运营数据（哪条爆了 / 词转化 / 话术成交） | 用户回填 + 各 skill | pulse-evolve |
| `个人风格.md` | 文风指纹（口头禅 / 语气 / 禁用词 / 金句） | pulse-init, pulse-humanize | 所有生成文本的 skill |


## Hub 索引机制

`项目档案.md` 维护一张"累积产出索引"表：

```markdown
## 累积产出索引

| 文件 | 状态 | 最后更新 | 摘要 |
|------|------|---------|------|
| 人群语料库.md | ✅ 已生成 | 2026-07-27 | 32 条用户原话，覆盖 5 类痛点 |
| 爆款素材库.md | ⏳ 待生成 | — | — |
| 话术资产.md | ✅ 已生成 | 2026-07-27 | 4 类话术，2 条已验证有效 |
| 数据反馈.md | 🔄 待回填 | — | — |
| 个人风格.md | ✅ 已生成 | 2026-07-27 | 从 Obsidian 笔记提炼 |
```

每个 skill 产出后**必须更新这张索引**。这样任何 skill 启动时都能快速判断"哪些资产已准备好"。

## 多项目支持

`~/.pulsehub/archive/` 下可以有多个项目目录。`pulse-init` 时通过项目名区分：

```bash
# 初始化新项目
> "新建项目：英语培训获客"

# pulse-init 会创建 ~/.pulsehub/archive/英语培训获客/ 并复制模板
```

切换项目时，在对话中说"切换到 XX 项目"即可，skill 会读取对应目录。

## 模板文件

本目录下的 6 个 `.md` 文件是**初始模板**。`pulse-init` 会复制它们到用户目录并填充对话收集的信息。

模板里有 `[待填写]` 占位符，`pulse-init` 运行时会替换为实际内容。

## 隐私与安全

- `~/.pulsehub/archive/` 是**本地文件**，不上传任何云端
- 不要把真实客户手机号 / 身份证 / 银行卡存进来——只留平台昵称 + 评论原话 + 意向度
- `数据反馈.md` 可能含商业敏感数据（转化率、客单价），建议 `chmod 600` 或加入 `.gitignore`
