# Interview Profile — 创始人 IP 深度访谈档案（模板）

> **使用说明**：
> 1. 复制此文件为 `interview-profile.md`（同一目录）
> 2. 跑 `/ip-strategy` 等子 skill 时会读取 `interview-profile.md`（非 .example）
> 3. 推荐通过 founder-ip 的访谈流程生成（说"创始人IP战略"等触发词），而非手动填写
> 4. **此模板版可公开**，你的真实 `interview-profile.md` 已在 `.gitignore` 中排除
>
> **填写原则**：越具体越好。模糊的档案 = 模糊的战略建议。

## 💡 填写提示

1. **不要自己瞎填**——推荐通过 `/ip-strategy` 的访谈流程生成，系统会用徐沪生 + dontbesilent + PLG 的方法论引导你
2. **越具体越好**——"ToB SaaS" 比 "软件" 好，"工程合同审核 AI" 比 "AI 工具" 好
3. **真实优于完美**——徐沪生第 5 章说"真实型人设"，你的档案也要真实
4. **锁定后不轻易改**——关键决策清单是战略锚点，改 = 重大事件，需要记录修订理由
