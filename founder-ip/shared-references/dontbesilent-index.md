## 为什么需要这个索引

徐沪生讲的是**创始人 IP 的"道"**——为什么做、不做什么、长期主义。
dontbesilent 讲的是**商业变现的"术"**——怎么定价、怎么对标、怎么转化、怎么避免商业幻觉。

两者**互补不冲突**：
- 徐沪生说"忘掉卖货卖课" [徐沪生 4.4] → dontbesilent 说"老子活着就是变现" [DB 2024Q4_275]
- 徐沪生说"优质内容是最好的运营" [7.2] → dontbesilent 说"没有人设的流量一文不值" [DB 2024Q4_096]

**子 skill 在给出建议时**，应同时引用两个视角，让用户自己判断。明示差异时用：
> ⚠️ 视角差异：徐沪生说 X，dontbesilent 说 Y。你的场景更适合 ___。

## 子 skill 引用指南

子 skill 在生成建议时，**鼓励同时引用徐沪生 + dontbesilent**，格式：

```
> 💡 双视角对照
> 
> 徐沪生 [徐沪生 X.Y] 说："原话"
> → 解读
> 
> dontbesilent [DB 原子ID] 说："原话"
> → 解读
> 
> 你的场景：[基于 interview-profile 判断]
> → 建议倾向 X 视角，因为 ___
```

**冲突处理原则**：
1. 徐沪生优先（founder-ip 的主方法论）
2. dontbesilent 作为"实战派补充"——当徐沪生没讲或讲得模糊时，引用 dontbesilent
3. 两者冲突时，明示冲突 + 让用户判断（基于 interview-profile 的具体场景）
4. **永远标注视角差异**，不让用户以为只有一个正确答案
