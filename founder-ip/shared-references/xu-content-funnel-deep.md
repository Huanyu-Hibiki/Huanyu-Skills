## 核心模型 ｜ 内容漏斗三层结构

> **一个 IP 账号相当于一本杂志。没有内容就无法破圈，要么有流量却没有转化。** [徐沪生漏斗 1]

```
┌─────────────────────────────────┐
│  顶层：破圈内容（最广受众）       │  ← 大师故事 / 审美 / 小而美的生存哲学
│  吸引更广泛的目标用户             │
├─────────────────────────────────┤
│  中间层：认知内容（目标用户）     │  ← 从业经验 / 行业洞察 / 专业判断
│  分享专业积累                     │
├─────────────────────────────────┤
│  底层：转化内容（购买意向用户）   │  ← 课程 / 服务 / 产品详情
│  给有购买需求的人看               │
└─────────────────────────────────┘
```

**关键原则**：
- 漏斗的每一层，功能不一样，但**底层逻辑、价值观、审美是统一的**
- 不讲与价值观不符合的成功人物故事，不推崇与价值观不符的方法论
- **漏斗外面的内容**（不相干的社会热点、娱乐话题）不要碰

## 经典案例 ｜ 蟑螂药怎么做个人 IP [徐沪生蟑螂药案例]

> **"徐老师，我是卖厨房杀虫剂的，俗称蟑螂药，我应该怎么做个人 IP 的内容呢？"**

### 错误做法
没人要看一个讲述蟑螂药功效的账号——除非你是娱乐天才，能把蟑螂药讲得让大家爱看爱传播。

### 正确做法（层层破圈）

```
蟑螂药
  ↓ （背后是厨房清洁）
厨房清洁 / 干净的厨房
  ↓ （厨房是家的一部分）
干净的家的场景
  ↓ （家的主人是爱干净的人）
居家生活方式
```

**具体内容设计**：
- **底层（转化）**：杀虫/清洁知识类视频
- **中间层（认知）**：又干净又好看的厨房视频（空间设计/功能设计/主人的清洁之道），适当给自己产品种草，**但切记不要种草过了头变成裸广告**
- **顶层（破圈）**：又干净又好看的家的视频（客厅/阳台/书房/主人的审美/生活态度），当人物故事来拍

### 核心洞察
> 通过内容，用户对你建立起信任。绝大多数受众对各种厨房杀虫剂没有辨别能力——过去看谁广告做得多，今天是通过个人 IP + 优质内容建立信任，从而建立对品牌的信任。

> 你甚至可以直播卖货——因为你有自然流量，不需要每时每刻靠投流拉流量。

## 破小圈，不破大圈 [徐沪生漏斗 5]

**不相干的热点不要碰**。理由：

1. **会污染用户画像**——全民热点吸引大批泛用户，破坏精准定位
2. **评论区环境破坏**——热点往往是争议性的，左右两边的人无法互相说服
3. **我不是这方面专家**——不专业的内容破坏人设

> 我们要向范围更大的分众去破圈，但**不要破圈到最大众的那一层**——那就等于没有用户定位了。

> 如果用户非常垂直、非常高净值，有时一个个人 IP 只需几千、几万粉丝，就可以有巨大的商业转化。

**除了热点，个人生活内容也要谨慎**：
> 我家有三只猫，但我不会去讲我的猫——它们和我的个人定位无关，我也不做宠物消费的生意。这一类内容万一成了爆款，反而麻烦，因为平台会给我推送大量的宠物爱好者。

## 既要又要还要 [徐沪生漏斗 6]

> **我们不能在一条视频上既要流量，又要转化，还要品牌。但是，我们可以通过一个 IP，通过不同功能的内容，实现既要又要还要。**

| 内容类型 | 功能 | 流量特征 |
|---|---|---|
| 追求转化的视频 | 商业转化 | 流量小但最精准 |
| 追求破圈的内容 | 扩大受众 | 用户范围更大 |
| 中间层内容 | 品牌塑造/企业文化 | 介于两者之间 |

> 如果简单一些，也可以只分两层：追求流量的内容、追求转化的内容。

> 如果没有"做一个账号"的意识，想在每个视频里既要又要还要，那就会彻底卡死——一条视频想成为爆款 + 卖货 + 说品牌理念，最后一定是**四不像**。

## 高频阅读与低频购买 [徐沪生漏斗 7-8]

> **购买是低频的，阅读是高频的。**

- 衣服一年买几季；喜欢的饭店一年吃不了十次；家电几年才换；家居建材可能十年才装修一次
- 一个人哪怕天天网购，对每个商品而言购买仍是低频的

**传统广告的逻辑**：不断触达用户，一次次塑造品牌心智，使用户有需求时想起自己。
**社交媒体时代的逻辑**：逻辑依然如此，只不过过去靠广告高频触达，今天靠**内容/视频**高频触达。

> 品牌必须进入用户主流的阅读场景。今天就是进入社交媒体、短视频，占据一席之地。反之，就等于没有营销。

## 该买的人迟早会买 [徐沪生漏斗 8]

> 购买是低频的，而且用户什么时候买，是很难预期的。

**传统广告界的名言**：
> "我知道一半的广告费是被浪费的，但我不知道浪费在了哪里。"
> → 浪费在无法预测用户购买行为何时发生。

**做个人 IP 的观察**：
- 永远有一部分用户是**积极的行动派**——一刷到视频，醍醐灌顶，立即联系合作
- 更多的用户是**理性消费者**——看了很久才来上课，上课后很久才谈合作

> 我们能把这些用户区分出来吗？不能。那就不做区分，**一视同仁**。

> 对于性子慢的用户，不需要"逼单"——逼单都是基于陌生用户的把戏，手段非常单一（永远是限时打折）。**创作优质内容，和用户形成长久的陪伴式关系，更纯粹。**

## 超级个体可以逐步成长 [徐沪生漏斗 9-10]

> **持续生产优质内容，就等于打造一档视频节目。** 这与娱乐网红持续输出纯粹个人特质的内容有巨大的差异。

**视频节目模式的核心 = 优质内容 + 超级个体**

出发点是**你的专业优势**：
- 设计公司创始人 → 优质设计内容（你比绝大多数人懂设计）
- 做食材的 → 美食节目（你有优势有资源，比绝大多数人懂吃）
- 工程合规创始人 → 工程合规内容（你有专业积累）

> 离开这个超越绝大多数普通人的优势，靠创始人去耍宝，就会陷入混乱，成功概率极低。

**成长路径**：
1. 一开始比较拘谨、被动，更像一个主持人（团队帮你找选题/做脚本/做节目）
2. 慢慢熟悉后，越来越有自信，越来越占据主导
3. 个性化的一面可以得到更大发挥

> 和娱乐网红模式相比，视频节目模式**开局往往更有保障，未来更能超越周期**。它不像讲脱口秀——卡死就是卡死，尴尬就是尴尬。

## 三种人设（深度展开）[徐沪生漏斗 11-13]

### 1. 内容型人设，而非卖货型人设 [徐沪生漏斗 11]

> 在人设问题上，大家最容易犯的错误，就是**只知道卖货**。

**典型错误**：
- 做服装品牌的，一打开都是自己的衣服
- 卖茶叶的，一打开都是自己的茶叶包装
- 做教育培训的，一打开都是自己教室里的场景

> 完全没有流量。因为你只是在说自己有多好，这不是内容，而是**广告营销**。有些人的个人 IP 做了很久，看起来像个**货架**。

> 在社交媒体上，我们要跟各种优质内容、娱乐内容、热点内容去竞争。你不能拿一个商品货架性质的内容，希望受众能够看得下去。

### 2. 专家型人设，而非娱乐型人设 [徐沪生漏斗 12]

> **专业性，是创始人 IP 和娱乐网红 IP 的本质区别所在。**

**案例：会跳舞的餐厅老板娘**
> 我有时会刷到我家附近一个餐厅老板娘的视频，她天天在那里健身、跳舞、搞笑。就算她有一点知名度，但我不会去这家餐厅吃饭——因为我觉得她不靠谱，不是一个认真开餐厅、认真钻研美食的人。
>
> 我不需要欣赏一个会跳舞的餐厅老板娘，我去餐厅是为了吃饭和请客。她的账号没有传达让我产生**信赖感**的内容。

### 3. 真实型人设，而非虚假型人设 [徐沪生漏斗 13]

> 设计人设，是指从商业模式出发去做设计，但这**并不等于**去设计一个虚假人设。

- 一个人无法长期扮演虚假人设
- 无须扮演完美的人设——假扮完美反而容易"塌房"
- 真实 ≠ 毫无保留地什么都讲——做 IP 迄今几乎没有提到自己的私人生活，完全不需要曝光隐私

> 真实，意味着我们不要过分封闭，可以与受众分享一些真实的感受，乃至非常私人化的感受。

> 所有的内容和表达都务求真实，**切勿虚构、模仿或抄袭**。此类错误一旦被用户发现、放大，后果往往超乎预料。

## 节目 IP：创始人不出镜怎么做 [徐沪生漏斗 14-15]

> 创始人不出来，并不意味着就不能做内容。

### 成功案例

| 品牌 | 节目 | 目标用户 |
|---|---|---|
| **山下有松**（包饰品牌）| 《山下声》系列节目 | 中产用户 |
| **GIADA**（意大利服装品牌）| 与鲁豫合作播客《岩中花述》| 都市年轻女性 |
| **米其林**（轮胎品牌）| 米其林餐厅评选（始于 1900 年）| 美食爱好者 |

### 节目 IP 的逻辑

> 今天，大多数品牌大号缺乏活跃度和流量，因为它们**只有广告，缺乏内容**。

> 一个调味品品牌的官方账号讲油盐酱醋，完全吸引不了读者。但可以打造一档短视频版的《舌尖上的中国》——报道各地特色美食、宝藏小店，因为有大量做菜的镜头，就可以把自己的各种调味品植入进去。

> 一个汽车品牌的官方账号讲自己的车有多好，没流量。但可以打造一个自驾游节目——讲最美的自驾线路、路上的民宿美食人文景点。有了山水道路，车子就可以在里面开起来，全程植入。

### 核心原则
> 用户关注的是优质内容，而不纯粹是个人。品牌有机会创办一个属于自己的"电视节目杂志"，打造一个和产品有内在联系的节目 IP，然后**自己独家冠名、全程植入**。

## 员工 IP 矩阵 [徐沪生漏斗 16-17]（新维度）

> **全新维度**——founder-ip 当前未覆盖，面向大型公司的扩展玩法。

### 案例：大型酒店集团
> 他们有一万个店长。原则上每个店长都可以做一个个人 IP，就算只做出几百个店长 IP，每个人全网一万粉丝，也是可观的数字。

### 关键原则
1. **统一方法、统一模式**——不为每个人做定制化设计
2. **走专业路线，不走娱乐化**——店长 IP 围绕酒店所在地，讲述对客人有用的周边旅游/美食/生活资讯
3. **账号归属权在公司**——换了店长，账号换人延续（内容一致，不依赖个人）
4. **不期望涌现超级网红，希望大多数人取得成果，聚沙成塔**

> 一家大型公司尝试过员工 IP 矩阵，很快放弃了——因为最后只有东北几个店长能拿到流量，无疑是走了娱乐化路线。
