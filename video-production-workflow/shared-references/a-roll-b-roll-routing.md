# A-roll / B-roll Routing（素材路由）

## 基本判断

```text
这段画面是否承担人物连续表达、情绪和主要叙事？
  ├─ 是 → A-roll
  └─ 否 → 它是在证明、解释、覆盖还是强化口播？
            ├─ 是 → B-roll
            └─ 否 → 可能是不必要的包装，不自动添加
```

## 分镜中的拍摄形式

| 拍摄形式 | 默认属性 | 适用内容 | 备注 |
|---|---|---|---|
| 实拍 | A-roll 为主 | 人物观点、情绪、叙事和总结 | 可抽取环境镜头作为 B-roll |
| OBS 录像 | A-roll 或 B-roll | 真实操作、界面、产品流程、证据 | 根据是否承担连续讲解判断 |
| Remotion 动效 | B-roll | 架构、流程、数据、对比、解释性图形 | 不负责整条主视频 |
| HyperFrames | B-roll | 标题卡、动态文字、UI、字幕、转场、浮层 | HTML 是源文件 |
| B-roll 动画设计 | B-roll | 文稿特定视觉隐喻和动作设计 | 需要先过机会分析和风格闸门 |
| AI 图 / AI 视频 | B-roll | 历史意象、抽象概念、不可拍摄场景 | 不可伪装成真实证据 |
| Stock 素材 | B-roll | 环境、地点、动作、产品和情绪补充 | 必须核验具体素材许可证 |
| 用户素材库梗 / 反应 | B-roll | 反应、节奏和文化语境强化 | Agent 不自动替用户寻找最终梗 |

## B-roll 路由决策

| 口播内容类型 | 优先素材 | 不应优先使用 |
|---|---|---|
| 具体人物、产品、地点、历史事件 | 官方或权威真实素材 | 与实体无关的通用文字卡 |
| 新闻、争议、投诉、当前数据 | 原始新闻、帖子、报告或截图 | 无来源的 AI 伪截图 |
| 数字、统计、增长或下降 | 数字本身、图表、仪表盘、真实页面 | 只放抽象装饰 |
| 流程、架构、决策树 | Remotion / HyperFrames / 真实录屏 | 强行用 Stock 代替解释 |
| 抽象观点或隐喻 | 概念动效、AI 隐喻、纸拼贴 | 与语义无关的关键词图片 |
| 情绪、反应和笑点 | 人物保留、用户提供的反应素材 | Agent 擅自搜索未经确认的梗 |

## 三个路由

1. **Receipts / 证据**：当前事件、引用、数字、争议 → 来源页面、新闻、帖子、报告、真实 UI。
2. **Entity / 实体**：人、产品、地点、历史事件 → 官方/权威视频或用户自己的素材。
3. **Concept / 概念**：流程、思维模型、抽象关系 → Remotion、HyperFrames 或已确认的 AI B-roll。

## 反例

- 句子说“某产品的真实界面”，不能用无关的科技素材代替。
- 句子说“研究表明”，不能用合成的引用卡冒充研究证据。
- 已经在画面中的人物本人，不应再以同一段 talking-head 作为 B-roll 切回。
- 不为了提高画面密度而给每句话塞 B-roll；保留人物本身也是节奏选择。
