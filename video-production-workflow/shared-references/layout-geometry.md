# Layout Geometry（排版几何规范：放哪、多大、怎么对齐）

> 处理"排版预算"（同屏放多少，见 [motion-brief-standards.md](motion-brief-standards.md) 第 6a 节）之外的另一半问题：位置、尺寸、对齐与碰撞。方法论原理吸收自 video-talkcraft（PolyForm-NC，仅原理自写，见 [external-references.md](external-references.md)）。
>
> 数值基准为 1920×1080 横屏；竖屏按画幅比例换算并重设安全边。适用于动效导演简报、Remotion/HyperFrames 场景实现与装配 QA。

## 1. 安全区与栅格

| 项 | 值（1080p 基准） | 说明 |
|---|---|---|
| 行动安全边 | 96px | 任何元素不得越过 |
| 标题安全边 | 160px | 大标题更靠内 |
| 字幕带保护区 | y ≥ 900 | 该带只放字幕，其他元素不进 |
| 有字幕时主体组底边 | ≤ 860 | 给字幕让位 |
| 栅格 | 12 栏，内容宽 1728，栏距 32，栏宽 ≈114.7 | 元素边缘吸附栏线，容差 ±4px |
| 常用跨度 | 全宽 12 / 主列 8 / 双列 6+6 / 一主两辅 7+5 | 跨度写进分镜版式行 |
| 竖向锚 | 中线 540、三分线 360/720 | 构图对位基准 |

## 2. 间距令牌与层级铁律

- 令牌只有 7 个：`8 / 16 / 24 / 32 / 48 / 64 / 96 / 160`——不出现令牌表之外的间距值；
- **层级铁律：外边距 ≥ 组间距 ≥ 组内间距**（如 96 ≥ 48~64 ≥ 16~32）。违反即"间距倒挂"——修法是把整组收进栏格重新归属，不是逐个改 margin；
- 元素离画幅边 < 64px 判"贴边"，记 P1（安全边内但贴边仍然是病）。

## 3. 对齐与居中

- 以**字形边缘**为准对齐，不以容器盒为准——带内边距的容器反向补偿后再对齐；
- 数字列用等宽数字（tabular-nums），多行数字上下对齐才不跳动；
- 标注（箭头/引线/框）的几何由**目标实测包围盒**反推，禁止目测坐标；定妆帧核对偏差 > 8px 返工；
- 居中指**主体组包围盒**居中，不是第一个元素居中；
- 人物在场时主体组放**对侧半幅中心**（1080p 即 x=480 或 x=1440），人脸安全区优先于居中；组中心偏离锚点 > 48px 判"偏一边"。

## 4. 字阶与字号下限

| 档 | 字号（1080p） | 用途 |
|---|---|---|
| hero | 96~120 | 一屏一个，只给最重要的词 |
| title | 64~72 | 章节卡 / 镜标题 |
| subtitle | 44 | 副标题 |
| body | 40~44 | 正文卡 |
| caption | 28~32 | 注释 / 来源 |
| micro | 22~24 | 极小标注（CTA/来源） |

- 最小可读 28；**列表条目和 chip ≥ 40**（小于它读起来像装饰不像信息）；
- 标题字数决定字号档（≤6 字 120；7~10 字 96；两行各 ≤8 字 84）——放不下先**删字**，再**拆行**，最后才**缩字号**，顺序不可倒；
- 同屏文字层级 ≤ 3 级；同屏 hero 与正文字号比 ≥ 2:1，否则层级感失效；
- 字重只用两档（常规 + 半粗），不用更重字重砸层级。

## 5. 碰撞与底板

- 任何两个元素的包围盒不得相交；刻意叠层只有三类豁免：标注压素材、字幕带、人物角标 chip 压 B-roll；
- 文字列宽 ≥ 最长行实测宽 + 2×内边距；溢出处置分档：差 1~40px 微调内边距 / 40~90px 收紧间距 / 90~160px 压标题档 / 超 160px **换版式**——不用 margin 硬救；
- 列表/chips 用淡底板色轮换，同组内不重复；章节标题卡按章轮换底色（同族不同章）。

## 6. 九项机检清单（QA 用）

装配/评审阶段逐镜核对，任一失败记 P1（前六项可脚本量测）：

1. 贴边：元素离画幅边 < 64px；
2. 间距倒挂：外边距 < 组间距或组间距 < 组内间距；
3. 未吸附：元素边缘偏离栏线 > 4px；
4. 偏居中：主体组包围盒中心偏离锚点 > 48px；
5. 标注脱靶：标注与目标实测偏差 > 8px；
6. 字阶违规：正文 < 40 或条目/chip < 40 或一屏层级 > 3；
7. 包围盒相交（三类豁免外）；
8. 同组同色：同组底板色重复 / 章节卡未轮换；
9. 390px 宽不可读（手机宽终检，口径同 [video-polish](../skills/video-polish/SKILL.md)）。
