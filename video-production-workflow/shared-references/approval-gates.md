# Approval Gates（审批闸门）

审批闸门控制方向、成本和不可逆操作。用户确认前可以继续做只读分析和草案，但不能执行对应的高成本或破坏性动作。

| 闸门 | 触发阶段 | 必须确认的内容 | 确认前允许 | 确认前禁止 |
|---|---|---|---|---|
| Gate 0 | `video-init` | 项目路径、标题和目录是否正确 | 检查路径、列出已有文件 | 覆盖已有文件、删除目录 |
| Gate 1 | `video-plan` | 分镜路由、拍摄形式、外部素材和动效候选 | 读取文稿、生成草案 | 批量下载、开始拍摄指令 |
| Gate 2 | `video-rough-cut` | 粗剪策略、目标比例、保留内容和输出方式 | ffprobe、读取缓存转录 | 修改原片、输出正式成片 |
| Gate 3 | `video-assets` | 来源范围、许可证要求和下载规模 | 搜索元数据、列请求 | 下载许可不明或大规模素材 |
| Gate 4 | `b-roll-finder` | B-roll 机会、密度、素材路由和风格 | 分析精剪 SRT、生成表格 | 擅自抓取/生成全部 B-roll |
| Gate 5 | `b-roll-generate` | 每个 slot 的引擎、视觉风格、AI 成本和静帧 | 写 brief、prompt、实现计划 | 未确认就调用付费视频模型 |
| Gate 6 | `b-roll-generate` 的拼贴路线 | 隐喻（Gate 1）、静帧（Gate 2）、首尾帧组装成片（Gate 3） | 前一阶段的设计和 QA | 跳过确认、只传单张参考图或未做首尾帧 QA 就生成 |
| Gate 7 | `video-polish` | B-roll 位置、字幕、音乐、音效和发布规格 | 生成预览和 QA 报告 | 覆盖 Final 或宣称已发布 |
| Gate OPT | `video-skill-optimize` | 证据、候选差异、留出分数和残余风险 | 记录、聚合、暂存、验证 | 自动采纳或覆盖生产 Skill |

## 确认格式

```text
请确认以下项目：
- 通过：BROLL-001、BROLL-003
- 修改：BROLL-002（隐喻不够具体）
- 暂不做：BROLL-004

回复“全部通过”、指定编号，或直接给修改意见。
```

部分通过时只推进通过项；修改项保留原版本并生成新版本；暂不做项记录到 manifest 的 `removed_or_deferred`，不能在后续重跑中自动恢复。
