# B-roll Timing And QA（B-roll 时间与质量规范）

## 时间锚点

1. 使用精剪后的 `Sub/master.srt` 确定最终输出时间轴，不使用原始录制时间码。
2. 从词级 ASR 或可映射的字幕行找到关键词时间。
3. 默认在关键词说出后 `+0.2s` 到 `+0.5s` 进入 B-roll；不确定时宁可稍晚，不要提前。
4. punchline、结论和反转可以在关键词后的节拍落画面。
5. 相邻 B-roll 间不要留下小于 1 秒的无意义人物碎片；必要时延长前一个 B-roll 到下一个开始。

## 词锚机器校验（动效/B-roll 落点可验证）

设计落点必须**可机器验证**，不靠目测和手敲近似秒数：

- **锚点查表生成**：动效重音的落点时刻一律从词级时间戳/`master.srt` 查表得出（对齐字幕锚字），禁止手敲"大概第几秒"——手敲落点做过早/过晚时静帧 QA 根本看不出来；
- **落点误差 ≤0.1s**：装配/QA 时逐锚点核对"词说出口的瞬间画面是否恰好在响应"，超差即回改；
- **镜尾保护带 ≥0.5s**：动效落点距该 B-roll 出点不足 0.5s 的，提前落点或把该动效挪进下一条——刚出现就被切走/被转场吞掉的强调等于没做；
- **未到拍不显形**：词锚未到的数字/图形/卡片必须完全不可见（opacity 0），禁止"压暗/灰显提前摆好"的预告式呈现；行内数字要连同后继字符一起 gate；
- **开镜不空台**：B-roll 开场到第一个动效锚点 >1.5s 的空窗必须有承载画面（真实素材延续/静帧/上一元素残留），不做"空画布干等词锚"。

## 节奏默认值

| 类型 | 默认时长 | 说明 |
|---|---:|---|
| 普通 B-roll beat | 2-4 秒 | 让观众看清内容，不为密度牺牲可读性 |
| 简单标题/关键词卡 | 1.5-3 秒 | 只承载少量文字 |
| 流程/图表解释 | 4-8 秒 | 复杂内容需覆盖完整旁白解释 |
| 片头 burst montage 单镜头 | 0.8-1.5 秒 | 只在一个有意设计的蒙太奇中使用 |
| AI 拼贴组装 | 通常 5 秒 | 以完整组装动作和尾帧停留为准 |
| 结论尾帧 | 至少 1 秒 | 让观众读完和理解 |

## 画面 QA

每次渲染后抽取所有 B-roll 中点、入点、出点和 B-roll↔人物接缝，合成检查网格。以下任一项存在时不通过：

- 源视频带有未处理的字幕、Logo、水印或陌生人 lower-third；
- 具体实体被无关的文字卡替代；
- 画面出现 letterbox、缩放模糊、错误裁切或半屏残片；
- B-roll 提前于关键词出现，或字幕被画面盖住；
- AI 视频出现假字、伪 Logo、错误 UI 或语义漂移；
- Remotion/HyperFrames 素材超出安全区、透明通道带黑底或帧率不一致；
- 镜头边界缺转场处置（裸切）、两侧运镜方向不连续（黑震式除外）、或退场后底床空转 >0.4s（段尾同收）；
- 排版几何九项（贴边/间距倒挂/未吸附/偏居中/标注脱靶/字阶违规/包围盒相交/同组同色/390px 不可读）任一失败——见 [layout-geometry.md](layout-geometry.md)；
- 口播和 B-roll 的音频发生爆音、重复对白或不必要的源音；
- 已确认的 B-roll 在新版本中消失，但 manifest 没有用户移除记录。

## 镜头边界转场处置（禁裸切）

每个镜头/B-roll 边界必须在分镜或装配清单里声明转场处置，QA 逐边界核对"有处置且两侧运动方向连续"（黑震式除外）：

- **运动承接族**：推穿 / 翻页过曝 / 甩镜 / 后拉冷却 / 粒子溶接——交叠 12-16 帧，两侧运镜同向承接动量（前镜加速出、后镜同向入），翻页过曝的包络不对称（切前升、切后降）；
- **遮挡 / 擦除族**：色块擦除、上下幕扫过——无相机系统时的轻量替代；
- **图形接力**：前镜的一条线/一个图形跑去后镜当容器——一支片只放一次，当招牌位；
- **黑震切**：全片限一次，留给最大反转；不是反转不配用；
- 一个边界只用一式；约 100s 的片 5-7 个强边界，重复同式比六式集邮更有连贯性；
- **长镜替代**：连续解释段可以不切——全部内容钉在同一画布坐标上、一台相机连续走位、新内容快到才成形；运镜速度 ≤1.5 屏宽/秒。

## 段尾同收（字与画同起同收）

每一镜/每条 B-roll 的**最后一个退场元素 = 段尾**：禁止"文字走了、底床还在空转 >0.4s"。落定即静置的定版画面（logo 落定、结论行）的静止不是豁免——由该镜的相机极缓推拉替它"活着"。QA 在每个出点前 1s 抽帧核对：退场完成后到切点之间画面仍有受控运动或恰好结束。

## 状态切换窗（隐形缺陷高发区）

人物角标↔满幅切换、字幕带换位、分屏↔全屏等**几何过渡窗口**的冲突只在句级抽帧里漏检——这些切换时刻前后 ±0.5s 强制进入抽帧清单；字幕带换位必须等几何过渡完成再切。渲染前的静态探针（每段渲相隔 0.8s 两帧算帧差）可以零成本预判静止类缺陷，母版渲染前先跑。

## 音频规则

- 口播覆盖型 B-roll 默认去除源音轨：`-an`。
- 必须保留现场声时，明确写入 B-roll manifest，并做音量自动化。
- 主视频每个切点使用约 30ms audio fade，避免爆音。
- 音效是动作提示，不要用持续音效掩盖口播；音效素材必须走许可证清单。
- **音效电平纪律**：单个音效在成片里的电平 ≤0.35（相对口径），整体比口播低约 12dB；同一时刻最多一条 cue，不叠双记；转场只配蓄势不配落点，金句/落幅/谢幕不加收尾叮当或重砸。
- **覆盖口径**："少而准"管的是单点不叠 + 音量克制 + 豁免清单（连续揭示类、纯文字金句、落幕留白），**不是砍覆盖面**——主要动效的入场要有音效响应，参考密度约 0.4 记/s（100s 片约 40-50 记）；音效 cue 随选定的动效模板/卡一起登记进时间线，再换算成绝对秒；
- **可听度机检**：独立音轨逐 cue 检查在窗 `[t-0.05s, t+0.45s]` 内峰值 ≥ -45dBFS（不在 = 没放）；混音后逐 cue 分级掩蔽——被人声完全掩蔽的 cue 等于没放；"未被掩蔽"条目的数量门槛要与全片气口数对账，**数学上不可达时早下结论**（如气口太少的片子），打印原因交用户，不硬凑；
- 字幕在最终 filter chain 的最后应用。

## 素材 manifest 规则

每条 B-roll 记录：编号、原句、时间、文件、来源、许可证、路由、版本、状态、用户确认时间和 QA 结果。新版本渲染前先读取 manifest，已批准条目不能静默丢失。
