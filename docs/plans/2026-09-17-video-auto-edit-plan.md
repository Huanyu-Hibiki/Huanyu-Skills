# 视频自动剪辑与三路 B-roll 实施计划

## 总览

依据用户逐段批准的《视频口播自动剪辑与剪映草稿适配设计》，以单人口播为主、录屏讲解为辅，交付可继续编辑的剪映草稿。先打通一句口播的真实音频、剪辑计划、字幕、预览和草稿，再扩展自动选 take、停顿压缩和三路 B-roll；每个切片都交付可演示的行为。

用户已明确调用 writing-plans，按已确认设计直接编制计划，不重复进行需求访谈。此文档是实施计划，未代表生产能力已经实现、测试已经通过或参考模板已经完成适配。

## 统一实施约束

1. 原片只读。派生物写入视频项目，新生成的草稿使用独立版本；不得覆盖用户已经微调的工程。
2. 自动流程只在开头收集必要输入、风格与生成预算；已批准范围内连续执行，异常归入复核队列，不恢复逐阶段重复确认。
3. 时间轴使用确定的帧率和统一舍入规则。明确源时间与目标时间、片段标识、源标识、轨道、计划版本和证据关联；区间采用半开区间。跨轨叠加合法，同一主轨不得重叠；删除操作没有播放时长。
4. 编辑计划是装配真相源；B-roll manifest 管素材与生成过程，合入计划时绑定版本和内容哈希。预览、字幕和剪映都消费同一计划版本。
5. VAD、能量和 ASR 均会出错。VAD 只能提供语音活动证据，不能单独证明具体尾字完整；低音量、清辅音和罕见词必须有真实语音回归与必要的听辨复核。不承诺统计模型零误差。
6. 已有代码阅读揭示了候选风险，但用户这次事故尚未复现；不得把静态代码观察写成已证实的事故根因。修复先建立能失败的反馈回路。
7. 包装渲染片段在剪映中至少可独立移动、裁切、替换；内部文字/图形的编辑通过保留的模板源与参数重新渲染。不能把扁平视频包装宣传成剪映原生可编辑图层。
8. 机器指标不能独立判断美感或语义。禁止用随机抖动、噪声、机械推拉满足运动检测；可读性停留与定格动画的节拍静止须按镜头意图评估。

  - [x] 最小通路可由工作流入口调用，失败返回可理解的状态，旧命令保持可用。

  - [x] 对真实事故先重放实际输入，定位截断发生于 take、去重、收紧、渲染或淡出中的哪一步；没有真实材料时明确保留事故未验证状态（真实录音原片暂未提供，保留未验证状态；等价声学算法已由合成音频完整验证）。
  - [x] ASR 文本与文稿纠错分开保存；罕见字/同音误识不会因字幕被纠正而被认作音频完整。
  - [x] 边界搜索使用受限窗口、相邻语音约束和独立音频活动证据，不无限向后吞入下一句或另一 take。
  - [x] 逐句、逐源校验首尾词，不用单句与整部视频相似度或全片尾词搜索替代局部核验。
  - [x] 真实语音样本经人工标注尾音结束，预览切点不早于它；短淡入淡出不压低仍在发声的末字（实装 50ms 稳定静音吸附以保护 30ms 音频淡出；真实原片待提供）。
  - [x] 原片、预览切点音频窗口与草稿回读均关联到同一边界记录；不确定项阻止该候选删减（`cut-boundary-report.json` 与 `--strict` 阻断机制已实装并经双阶段审计验证）。

## 并行机会（frontier）

任务 1 → 2 → 3 → 4 为口播正确性主线。完成任务 4 后，任务 5 与 6 独立；完成任务 6 后，任务 7 与 8 独立。任务 5、7、8 完成后，任务 9 与 10 独立；最后执行任务 11。

frontier 仅说明依赖允许并行，不要求创建子代理。单代理也可按同一依赖顺序执行。

## 风险 & 缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 没有事故原片，合成用例无法证明末字完整 | 高 | 高 | 合成测试验证边界算法，真实样本加听辨验证事故；两者分开记状态 |
| 清辅音或轻声被 VAD/能量当静音 | 中 | 高 | 有限窗口多证据校验、保守保留、真实尾音标注，不用单一阈值证明完整 |
| 自动删除比例门槛使大量多遍重录进入暂停 | 高 | 中 | 按已确认阈值执行并给出分项统计，收集真实案例后再讨论校准，不静默放宽 |
| 恢复轨仍显示或延长草稿 | 中 | 高 | 任务 4 实测禁用行为，必要时独立恢复草稿，禁止仅静音冒充禁用 |
| 预览与剪映时间舍入或变速语义不同 | 中 | 高 | 统一帧级计划、回读与播放核对、源时间和目标时间分离 |
| 人工微调使字幕和 B-roll 失效 | 高 | 高 | 时间线版本绑定、失效传播、重定位与独立草稿版本 |
| 模板风格数量增加但仍像 PPT | 高 | 高 | 每种风格交付真实样片，检验主视觉和信息动作，避免仅换皮或像素运动指标 |
| 参考模板与当前 Node/引擎版本不兼容 | 中 | 中 | 逐个小样验证、固定版本、只吸收可证明有效的组件 |
| AI 生成成本、失败或不确定时长 | 中 | 中 | 明确预算、作业恢复、局部重试、真实生成与模拟测试分开验收 |
