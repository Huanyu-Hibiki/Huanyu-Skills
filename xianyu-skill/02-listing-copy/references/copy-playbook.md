# 爆款文案结构模板（copy-playbook）

> 素材来源：`template/店铺参考/` 7 家同赛道店铺的真实文案（数据见 `shared-references/benchmark-shops.md`）。本文件是"从爆款里验证过的结构"，写正文时按段取用，不要逐字抄袭任何一家——结构可迁移，句子要用自己的。

## 一、标题公式库

### 关键词分层（搜索逻辑）

闲鱼搜索吃标题关键词，同赛道买家的搜索词集中在：

| 层级 | 词 | 例 |
|---|---|---|
| 品类词（必带） | skill、技能包、AI 工具、资料包、提示词、教程、源码 | "剪映自动化 skill" |
| 场景词（选带） | 自动化、一键、批量、复刻、拆解、搭建 | "爆款视频拆解" |
| 平台词（选带） | Claude Code、剪映、即梦、Coze、GPT | "适配 Claude Code" |
| 人群词（选带） | 新手、小白、创作者、自媒体 | "新手也能上手" |

### 三个标题句式（对应 SKILL.md Step 2 的 A/B/C 版）

1. **搜索版**：`核心词｜能力1+能力2+能力3`——用全角竖线分区是同赛道通行写法（店铺2/3/6/7 均用）
2. **痛点版**：`还在…吗？/ 别再…了` + 解法一句（店铺6 的"还在手动拖素材、一句一句对字幕？"是标准范式）
3. **人群版**：`给…的你 / 适合…的人` + 门槛消除（"不会编程也能用""免费教学"）

### 标题禁忌

- 超 30 字（列表页截断，后半句白写）
- 出现"最/第一/独家/官方"（绝对化与冒充官方）
- 全表情符号或全英文（中文搜索权重归零）

## 二、正文六段式（逐段拆法）

### 1. 首句钩子

**作用**：决定"划到的人停不停"。写法：`是什么 + 给谁`一句话，可带一个具体数字或反差。

- 正例（店铺7）：「把参考短视频拆成分镜、运镜与可执行的 AI 视频提示词」——动词开头，交付物具体
- 正例（店铺2）：「缠论AI Skill方法论合集｜结构化流程＋8道自检门」——竖线前品类后差异点
- 反例：「超好用的AI神器！！不懂的来看」——信息量为零

### 2. 这是什么（定位段）

1-2 句讲清商品本质与使用方式。参照店铺2 的范式：「这个是配置到 AI 上的技能包，配置好，直接对话使用」。**虚拟商品的"使用形态"必须在这里讲明白**（是文件？是配置教程？是源码包？），不然咨询量爆炸、转化率暴跌。

### 3. 能解决什么（卖点段）

✅ 列表 3-6 条。**每条必须是"能力 + 收益"双元素**：

- 弱写法：「支持自动字幕」
- 强写法（店铺6）：「自动字幕 — 中文+英文双语字幕，毫秒级对齐，不用自己一句一句打」——能力、规格、省掉的麻烦三合一

条数超过 6 条就合并同类项；宁可 4 条强的，不要 8 条弱的。

### 4. 内含什么（内容清单段）

数字化背书是同赛道爆款的通用信任手法（店铺2 的「8 本经典、11 篇细则、100 只 A 股实测回测、百万 token 反复烧」；店铺3 的「assets/ 13 个资源文件…templates/ 4 个模板」）。写法：按交付物结构列数字清单。**没有数字就老实用文件结构描述，不编数字**。

### 5. 怎么交付（交付段）

同赛道爆款的标准句式：「拍下秒发网盘链接，手机电脑都能看，永久保存」（店铺4）。三要素：**怎么发 + 什么设备能用 + 保存多久/更新政策**。使用门槛照实写（店铺4「需基础 Python 环境」——门槛诚实反而是筛选精准买家的过滤器）。

### 6. 售后说明（免责段）

同赛道全店铺标配，模板：

> 虚拟商品，一经发货不退不换；发货后请及时查收，有问题随时私聊，看到必回。

进阶版（店铺7）：追加用途限制声明（"仅供个人学习交流，请勿转卖或二次分发"）——同时降低盗版传播的道德成本。

## 三、情绪与信任要素库

| 要素 | 写法 | 参照 |
|---|---|---|
| 成本苦衷 | "真啃书＋真回测＋真烧 token"——展示笨功夫 | 店铺2 |
| 权威背书 | 被官方收录/有服务案例/实测数据 | 店铺3、5 |
| 降门槛承诺 | "你不会用，可以免费教学" | 店铺5 |
| 效率对比 | "原本 2-3 小时 → 现在 3 分钟" | 店铺6 |
| 体量证据 | "已帮 200+ 人告别手动剪辑"（**必须真实**） | 店铺6 |
| 价格自信 | "敢报这个价，必有一定的实力" | 店铺6 |
| 行动指令 | "点击右下角'我想要'直接拍" | 店铺6 |

用法：一段正文放 2-4 个要素即可，堆满显得油腻。信任要素必须可验证——编造背书被买家戳穿 = 商品下架 + 店铺扣分。

## 四、emoji 与排版规范

- ✅/⚠️ 等符号用于列表标记（同赛道通用），全文不超过 8 处
- 分段：手机端每段 ≤ 3 行；段落间空行
- 竖线 `｜` 与 `—` 用于分隔信息，比括号清爽
- 不用大段引用、不用井号话题标签（闲鱼不吃 hashtag）

## 五、价格带参照（来自 benchmark 数据）

| 价格带 | 同赛道定位 | 配套文案策略 |
|---|---|---|
| 2.99-6.99 | 引流款：走量、冲销量基数 | 文案短，强调"拍下秒发""随便试试" |
| 9.9-19.9 | 主力款：品质与价格平衡 | 完整六段式，数字背书拉满 |
| 29+ | 利润款：强调服务与教学 | 突出"免费教学""服务案例""一对一" |

定价前先跑 03-hot-analysis 看同赛道爆款价格带，不要闭眼定。
