# 闲鱼合规红线清单（compliance-checklist）

> 依据：`template/闲鱼规范/闲鱼.md`（《闲鱼社区信息发布规范》《闲鱼社区用户行为规范》《闲鱼社区交易争议处理规范》）。适用范围：**商品标题、正文、图片上的文字（闲鱼对图片做 OCR 审核）、私聊话术模板**。发布前逐项过表，任何一项命中 → 改写后重检。

## 第 1 关 · 类目准入（过不了直接拒写）

| # | 检查项 | 判定依据（规范条款） |
|---|---|---|
| 1.1 | 商品不是外挂/私服/游戏作弊工具 | 第三条（九）：作弊/造假工具、游戏外挂禁售 |
| 1.2 | 不是代刷/代炒/代投票/学术代做等代运营服务 | 第三条（七）：代炒作、代投票、考试作弊禁售 |
| 1.3 | 不是翻墙/代理/接码/群发等灰产工具 | 第三条（七）（十）：翻墙软件、接码平台、群发设备禁售 |
| 1.4 | 不是批量账号/多开/IP 修改类工具或教程 | 第三条（十）：批量账号设备禁售 |
| 1.5 | 不是"不可查询的虚拟服务"或充值类 | 第三条（十二）：不可查询虚拟服务禁售 |
| 1.6 | 不承诺投资收益/荐股/必涨信号 | 第三条（七）：非法服务；涉金融类表述需去建议化（"辅助研究，不构成投资建议"） |
| 1.7 | 不涉及药品/医疗/保健功效表述 | 第三条（六） |
| 1.8 | 无盗版风险：不售卖明确盗版资源的"搬运包" | 第三条（十一）：侵犯著作权禁售 |

**同赛道边界提示**：股票分析类 skill（如缠论）可发，但文案必须写"辅助研究/结构化流程/少做错单"，不得出现"必涨/胜率 XX%/带你翻倍"（店铺2 的"不是必涨信号机，而是…帮你少做错单"就是合规写法范本）；AI 视频拆解类可发，但不得含未授权影视资源本体。

## 第 2 关 · 违禁词扫描（标题 + 正文 + 图上文字）

| # | 词类 | 例词（包含变体） | 处理 |
|---|---|---|---|
| 2.1 | 绝对化用语 | 最、第一、顶级、独家、全网最全、史上 | 删除或改客观描述 |
| 2.2 | 收益承诺 | 稳赚、必涨、包过、躺赚、月入过万、保本 | 删除，改"辅助/提升效率" |
| 2.3 | 冒充官方 | 官方、官方授权、闲鱼官方、内部渠道 | 删除 |
| 2.4 | 医疗功效 | 治疗、治愈、根治、瘦身 | 删除 |
| 2.5 | 虚假数据 | 编造的销量、用户数、评价 | 无真实来源的数字全删 |
| 2.6 | 低俗擦边 | 擦边、福利、原味类暗示词 | 删除 |

## 第 3 关 · 平台行为红线

| # | 检查项 | 依据 |
|---|---|---|
| 3.1 | 无站外引流：不含微信号/QQ/手机号/二维码/"看主页"/"私聊发链接到邮箱"等任何形式 | 用户行为规范（五）：诱导站外交易 |
| 3.2 | 无"刷单/互赞/冲销量"等诱导表述 | 用户行为规范（五）：数据造假作弊 |
| 3.3 | 在线商品数未超 50 件（提醒用户自查） | 用户行为规范 三 |
| 3.4 | 不借用热点话题炒作引导 | 第三条（十三）：借用话题/内容炒作引导 |

## 第 4 关 · 虚拟商品披露完整性

| # | 检查项 | 不写的后果 |
|---|---|---|
| 4.1 | 交付方式写明（网盘/自动发货/文件） | 纠纷时按争议处理规范不利解释 |
| 4.2 | 退款政策写明（虚拟商品发货后不退不换） | 买家援引"无理由"要求退款 |
| 4.3 | 使用门槛写明（需什么环境/基础/付费依赖） | 描述不符 → 退货退款（规范 第一百条/第十六条） |
| 4.4 | 交付标准写明（包含哪些内容、数量） | 虚拟物品数量不足按比例退款（第一百零八条） |
| 4.5 | 用途限制写明（个人学习交流、禁止转卖分发） | 盗版扩散失控 |

## 第 5 关 · 图片文字专查（配合 01 出图使用）

- 图上文字与标题/正文**信息一致**（图说 A 文案说 B = "信息要素不一致"，第三条（十三））
- 图上不得出现站外联系方式（含背景装饰里的小字二维码）
- 图上不得出现竞品品牌负面对比、冒用他人 logo 当背书
- AI 生成的图上文字需逐字校对（生成模型易输出错别字与乱码，乱码会被 OCR 误判为垃圾信息）

## 自检输出模板

```markdown
## 合规自检（YYYY-MM-DD）
- 第 1 关 类目准入：✅ 通过（说明：AI skill 资料包，非禁售类目；涉股内容已去建议化）
- 第 2 关 违禁词：✅ 通过（已替换"最强"→"完整"；删除"月入过万"）
- 第 3 关 行为红线：✅ 通过
- 第 4 关 披露完整：✅ 通过（交付/退款/门槛/标准/用途五要素齐全）
- 第 5 关 图片文字：✅ 通过 / ⏸ 图片未出，出图后复检
- 结论：✅ 可发布
```

**原则**：自检不通过的文案不出手；用户要求保留违规表述时，说明对应后果后仍坚持的 → 拒绝执行该项并在对话中留档。
