## A · 研究档案风（数据最好的风格，优先推荐）

**参照**：店铺2 轮播全套（封面 → 来历 → 8 道门 → 图解）。

**视觉 DNA**：
- 底色：米白纸感 `#F7F5EF` + 细网格线（`repeating-linear-gradient`，1px `#E4E0D5`，间距 48px）
- 主色：藏青 `#16243D`（大标题、深色块）+ 青绿 `#0E7C6B`（强调词、图标）+ 一处金橙 `#C98A2D`（可选点缀）
- 字体：标题 Noto Serif SC 900（衬线大字是灵魂），正文 Noto Sans SC，元数据用等宽（JetBrains Mono / monospace）
- 版式骨架：顶部档案头（左：等宽小字系列名，右：编号 `NO.01 · 主题 × AI`）→ 分隔线 → 小字导语（`//` 前缀）→ 衬线大标题（每行 4-6 字，强调词换青绿色）→ 内容区

**关键组件**：
- 数字背书卡：2×4 白底描边卡，大数字（衬线）+ 小字说明（如"8 本经典 / 100 只个股 / 百万 token"）
- 编号清单卡：左侧深藏青方块白字编号（01/02/…），右侧白底描边卡写条目
- 底部胶囊徽章：描边圆角条 + 图标 + 关键词（如"开源 · 自取 · 仅供研究"）
- 深色结语条：整宽深藏青条内放一句金句，关键词青绿高亮

**CSS 要点**：
```css
body { background:#F7F5EF; }
.grid-bg { background-image:
  repeating-linear-gradient(0deg,#E4E0D5 0 1px,transparent 1px 48px),
  repeating-linear-gradient(90deg,#E4E0D5 0 1px,transparent 1px 48px); }
h1 { font-family:'Noto Serif SC',serif; font-weight:900; color:#16243D; }
em { font-style:normal; color:#0E7C6B; }
```

**缩略图风险**：浅底深字天然可读；风险在标题过长——每行不超过 6 字、最多 3 行。

## B · AI 海报风（转化背书最强）

**参照**：店铺3 封面（达尔文进化隐喻 + 循环图 + 徽章墙）。

**视觉 DNA**：
- 底色：深炭黑 `#141414`，可用暗纹理/手稿元素做氛围
- 主视觉：**AI 生成的隐喻图像**（人物/进化/机器等强叙事画面）占画面上半 50-60%
- 强调色：科技蓝发光 `#3EA6FF` + 金色徽章 `#F5C842`
- 版式骨架：主视觉 → 大标题（金属质感或粗黑体，关键词换色）→ 副标题 → 图标能力行（5 个图标+两行小字）→ 金色徽章条（权威背书）→ 平台兼容行（图标+名称横排）

**制作流程**：主视觉用生图工具产出（提示词写"具体视觉特征+内容+技术参数"，不写抽象词），其余全部 HTML 排版叠加；无生图条件时退化为 C 风格纯排版。

**关键组件**：
- 信任徽章条：金色描边 + 徽章图标 + "已收录至 XX 官方名单"式背书（**必须真实**）
- 平台行：Claude Code / OpenClaw / OpenCode 等平台 logo + 名称横排，标注兼容性
- 能力行：线性图标（描边风格统一）+ 能鼎词 + 一行小字

**缩略图风险**：深底画面缩略后细节丢失——大标题必须占宽 80% 以上、字号 ≥100px（1080 画布）。

## C · 暗色科技风（产品力自证）

**参照**：店铺5 封面（大字标题 + 产品截图矩阵 + 紫色晶体）。

**视觉 DNA**：
- 底色：近黑 `#0A0A12` → 深紫渐变 `#1A1030`
- 强调：白 `#FFFFFF` 大标题 + 霓虹紫 `#8B5CF6` / 电光蓝 `#4CC3FF` 描边光效
- 版式骨架：顶部 2/3 为超大标题（2 行内）+ 副标题 → 版本胶囊标签行（描边 pill）→ 中部产品截图**倾斜堆叠**（主截图 + 副截图错位，带发光描边）→ 底部渐变横条写交付转化（"图片/截图/PDF → 可编辑 PPT"式箭头句）

**关键组件**：
- 截图堆叠：`transform: rotate(-3deg)` 主图 + `rotate(4deg) translate` 副图，白色 2px 描边 + `box-shadow: 0 0 40px rgba(139,92,246,.5)`
- 胶囊标签：描边圆角 999px，双标签并排
- 箭头转化条：底边横条，`背景: linear-gradient(90deg,#8B5CF6,#4CC3FF)`，白字

**缩略图风险**：截图缩小后成噪声块——截图仅作氛围，信息必须由标题和底部转化条承载。

## D · 流程图海报风（效率叙事）

**参照**：店铺6 封面（流程管线 + 效率对比 + CTA 横幅）。

**视觉 DNA**：
- 底色：深黑 `#0D0D0D` 带轻微桌面场景元素
- 主色：银白金属字标题 + 橙红 `#FF4D1C` 强调 + 底部红金 CTA 横幅
- 版式骨架：顶部超大标题（产品名）→ 橙色效率对比条（"3 分钟完成原本 2-3 小时的剪辑"）→ **横向流程管线**（5 个图标节点 + 发光箭头连接）→ 中部产品界面大截图 → 图标特性行（6 个：图标+双行小字）→ 底部 CTA 横幅

**关键组件**：
- 流程管线：等宽排布的图标节点（描边发光方块 56×56 内含 icon），节点间 `→` 用发光线条；流程即卖点（写文案→配音→字幕→匹配画面→导出）
- 效率对比条：橙底白字或描边框，突出时间对比数字
- CTA 横幅：整宽横条，红金渐变，一句行动语 + "新手也能上手"式降门槛话术

**缩略图风险**：元素最多、最容易糊——严格控制在标题/流程/CTA 三个层级，截图区允许简化。

## E · 霓虹场景风（泛娱乐/创作者向）

**参照**：店铺7 封面（霓虹大字 + 手机样机 + 双能力卡）。

**视觉 DNA**：
- 底色：深蓝黑 `#0A1030` + 舞台光晕（径向渐变青/品红）
- 主色：白 + 霓虹蓝 `#2E9BFF` + 霓虹粉 `#FF3D8A` 双色对撞，`text-shadow` 多层发光
- 版式骨架：顶部双色大字标题（蓝白粉三段）→ 中央手机样机（真实界面截图）→ 左右两张霓虹描边能力卡（图标+词）→ 底部霓虹胶囊条（"分镜 + 提示词"式组合卖点）

**关键组件**：
- 手机样机：圆角矩形 + 顶部刘海条 + 内嵌真实截图，外发光 `box-shadow: 0 0 60px rgba(46,155,255,.45)`
- 能力卡：斜置 8deg 描边卡，图标 + 单词，左右对称各一
- 发光字：`text-shadow: 0 0 18px currentColor` 叠 2-3 层

**缩略图风险**：最稳的风格之一（大字+高对比）；注意发光别叠过头导致笔画粘连。

## F · 简洁信息卡风（快速出图）

**参照**：店铺1（白底结构化信息卡）。

**视觉 DNA**：
- 底色：纯白 `#FFFFFF`
- 主色：深灰 `#222` 标题 + 灰蓝 `#5B7A99` 表头底 + 单一强调色
- 版式骨架：编号大节标题（"1、这是什么"）→ 短段落 → 信息表（左侧灰蓝表头列：类型/适用对象/核心能力/使用流程）→ 章节分隔线

**适用**：时间紧、资料包类、或作为套图中的"说明书页"。信息密度最高但吸引力最低——不建议做封面主样式，适合当轮播第 2-3 页。

## 选风格决策树

```text
商品有强背书（官方收录/奖项/硬数据）？
├─ 是 → B AI 海报风（无生图条件 → C）
└─ 否
   ├─ 商品有漂亮成品截图/演示？
   │  ├─ 是 → C 暗色科技风
   │  └─ 否
   │     ├─ 卖点是"省时间/自动化"？ → D 流程图海报风
   │     ├─ 卖点是"内容厚/方法论/可复核"？ → A 研究档案风
   │     ├─ 面向创作者/泛娱乐人群？ → E 霓虹场景风
   │     └─ 只要快速上架？ → F 简洁信息卡风（做轮播页）+ 任一风格做封面
   └─ 拿不准 → 默认组合 A + C + D 出三版预览（Step 2 稳妥组合）
```
