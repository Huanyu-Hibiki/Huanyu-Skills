# Obsidian skill output routing for shendu-yuedu / sy-practice

Use this when converting reading knowledge cards into executable skills.

> `<知识库根>` 解析协议见 `../../01-init/SKILL.md`「知识库根目录解析协议」——用户未指定时默认当前 Agent 打开的项目路径。

## Durable routing rule

`sy-practice` has two output classes:

1. **Reading-process evidence** stays in reading notes:
   - Base: `<知识库根>/阅读笔记/`
   - Per book: `阅读笔记/YYYY-MM/<书名>/`
   - Per chapter: `阅读笔记/YYYY-MM/<书名>/<章节名>/`
   - Examples: `原始笔记.md`, `知识卡片.md`, `实践转化.md`, `复盘.md`

2. **Executable skills extracted from the book** go to the vault-level skills layer:
   - Root: `<知识库根>/skills/`
   - One book: `skills/<书名>/INDEX.md`
   - One executable skill: `skills/<书名>/<skill-slug>/SKILL.md`
   - Cross-book index: `skills/INDEX.md`

## Required indexing steps

When `sy-practice` creates or edits a book-derived skill, update all three indexes:

1. `skills/INDEX.md` — cross-book executable skill index.
2. `阅读笔记/_system/用户阅读报告.md` — section `已萃取技能索引（跨书累积）`, with skill name, source book/chapter/card, trigger, and path.
3. `wiki/index.md` — Skills navigation section, or create/update a `wiki/concepts/<书名>-技能索引.md` page when the book yields multiple reusable skills.

## Boundary

Do **not** put executable book-derived skills under:

- skill 安装包目录下的 `project-archive/` 等子目录
- `阅读笔记/_system/技能库.md`
- `阅读笔记/YYYY-MM/<书名>/技能合集.md` as the only source of truth

Those locations may contain notes or links, but the callable skill asset lives under `<知识库根>/skills/`.

## Relationship to 知识库 SKILL.md

`<知识库根>/SKILL.md` is the vault-level schema / operating constitution. It defines directory responsibilities and how agents should handle `阅读笔记/`（wiki + raw）、`skills/`、and `wiki/`. Follow it when writing into the vault. It is generated by `sy-init` Round 0 bootstrap if absent.
