# 自助获取书籍真实目录配方

> 2026-08-18 《价值心法》（姜胡说）拆解实战沉淀。当天 web_search(Tavily) / web_extract / curl 全部连不上，Playwright MCP 浏览器 + cn.bing.com 全程可用。sy-decompose 置信度门控判"中/低"时，先走本配方，取不到再问用户。
> **v2（同日用户纠错后重写）**：v1 的提取代码带正则过滤，把节级小节全部滤掉，只留章级标题，下游据此生成的问题清单与实际内容完全不搭，被用户拆穿。本版修正提取方式并新增完整性自检。

## 步骤

1. **Bing 精确短语搜索**：`https://cn.bing.com/search?q="书名"`
   - ⚠️ 书名必须加英文双引号。不加引号的中文书名会被分词（"价值心法"→"价值"），返回百科/词典/哲学词条等泛结果。
   - 结果里重点认三类链接：
     - `weread.qq.com/web/reader/...` —— 微信读书网页版，取目录主入口
     - `book.douban.com/subject/...` —— 豆瓣，交叉验证（注意与同名书区分，如张磊《价值》≠ 姜胡说《价值心法》，核对作者名）
     - `baike.baidu.com/item/...` —— 百度百科，元数据（出版社/出版年/页数/ISBN）
2. **微信读书取目录（无过滤全量提取）**：
   - 直接 navigate 到 reader URL（很多书不登录也能看目录面板）
   - 打开目录面板：`document.querySelector('.readerControls_item.catalog')?.click()`，等 ~1s
   - **全量**抽取（⚠️ 不得加任何会丢弃条目的内容过滤正则）：
     ```js
     () => {
       const items = document.querySelectorAll('.readerCatalog_list_item');
       const out = [];
       items.forEach(li => {
         const inner = li.querySelector('[class*="readerCatalog_list_item_inner"]');
         const lvl = inner ? ([...inner.classList].find(c => /level/.test(c)) || '') : '';
         const t = (li.querySelector('.readerCatalog_list_item_title_text')?.innerText || '').trim();
         out.push((lvl.includes('level_2') ? '    ' : lvl.includes('level_3') ? '        ' : '') + t);
       });
       return {total: out.length, text: out.join('\n')};
     }
     ```
   - 目录面板若被关闭，重新点目录按钮再抽；搜索框过滤后列表会重渲染，需清空搜索再全量抽。
3. **完整性自检（必做，防 v1 事故复发）**：
   - **层级检查**：结果里必须同时出现章级和节级（level_2/level_3 有值）。若全是章级 → 先怀疑提取代码丢了小节，重抽；确认书本身无小节才可按章级落盘（如《价值心法》第十六章"阳谋！"确无小节，是个例不是通例）。
   - **计数检查**：`total` 应为全书条目数（扉页/版权/序/导言都算），《价值心法》= 174。异常少（如 20-30 条）多半是面板没加载完或过滤残留，等待后重抽。
   - **复抽验证**：对存疑条目用目录面板搜索框搜关键词，看列表重渲染后条目是否仍在原位（v1 事故中第一章"提取痛苦清单""提取他人的成功方法"两小节靠二次搜索确认非爬取错误）。
4. **元数据交叉验证**：把百科/豆瓣摘要里的出版社、出版年、页数、字数、ISBN 抄进拆解文件「书籍概览」，结构来源写"微信读书网页版节级真实目录（N 条）"，置信度标"高"。

## 边界

- 遇到登录墙/人机验证 → 立刻停，请用户操作（全局硬规则，绝不自行绕过）。
- **电子版 vs 纸书存在版本差异**（实测：《价值心法》第一章纸书目录 7 小节、微信读书 9 小节，多出"提取痛苦清单""提取他人的成功方法"；第三章用字"制定/制订"不同）——以用户实际阅读载体为准，差异写进拆解文件备注；用户贴纸书目录来对照时逐条 diff，不默认自己抓的更权威。
- 抽完先 `date "+%Y-%m-%d"` 确认当前月份，再落 `阅读笔记/YYYY-MM/<书名>/00-拆解目录.md`，并回写 Hub 在读书目索引。

## 实证结果（2026-08-18）

《价值心法》：台海出版社 2023-06，564 页，25.7 万字，代序+导言+23 章，微信读书免登录抽取节级目录 174 条（level_1/2/3 三级，含 Part 分卷）。全程 Playwright MCP 完成。

## 事故记录（为什么有 v2）

v1 提取代码在 `document.querySelectorAll` 后用 `/第|章|前言|序|目录/` 正则过滤 innerText——本意去噪，实际把**全部节级小节标题**滤掉，只留章级。随后在 SKILL.md 里写下错误结论"微信读书网页版目录通常只到章级"，并按章级标题生成了与实际内容完全脱节的问题清单（第一章实际讲函数/IPO/重构，问题却问"产品线/渠道"）。用户质问"你问的这些问题是参考具体内容输出的吗"后全链路返工。教训：**提取环节的过滤器就是信息杀手；抓取产物的完整性必须显式自检，不得用"平台只有这个精度"合理化提取缺陷**。
