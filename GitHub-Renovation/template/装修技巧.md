- **仓库的 description 就是 Google 搜索结果的标题**。GitHub 仓库页的 `<title>` 格式是 `owner/repo: description`，Google 直接取它展示。你给 Huanyu-Skills 写的那条（关键词前置、中文为主尾缀英文）就是范本。

## SEO技巧

GitHub SEO 是优化你的仓库和个人资料，使其在 GitHub 内部搜索 和 Google 等外部搜索引擎 中排名更高的一套方法。核心就一句话：让机器（搜索引擎）能读懂，更让用户（开发者）愿意点进来。

下面是一份可直接操作的全方位指南：

🚀 一、优化仓库元数据（基础中的基础）

· 仓库名 (Repository Name)：最重要的排名因素，用连字符连接关键字，例如用 react-markdown-editor 而非 my-project。
· 描述 (Description)：显示在搜索结果中，权重极高。控制在 350 字符内，前120字符最关键，务必自然嵌入主要关键词。
· 主题标签 (Topics)：类似标签，可添加最多 20 个。建议包含技术栈 (react, python)、项目类型 (cli, web-app)、领域 (machine-learning, data-viz) 等。
· About 区域：在仓库首页右侧，用简短语言说明项目核心价值。
· 网站 URL (Website)：如项目有官网或文档站，务必在设置中填上。

📝 二、打造 SEO 友好的 README（内容为王）

· 标题与首段：使用带关键词的清晰标题，第一段就自然地包含核心关键词。
· 内容结构：使用 ##、### 等标题分层（安装、使用、贡献等），搜索引擎喜欢结构清晰的文档。
· 内部链接与图片：链接到相关项目或文档；为所有图片添加描述性 alt 文本。
· 丰富元素：添加 shields.io 状态徽章，代码示例、截图或 GIF等，提升可读性和专业感。
· 文件命名：代码和文档文件名使用 kebab-case（如 network-discovery.md），并包含关键词。

🌐 三、GitHub Pages 的 SEO（额外加分项）

如果你用 GitHub Pages 托管文档或博客，还要额外做：

· Meta 标签：在 index.html 的 <head> 中添加 title、description 等。
· 结构化数据：添加 JSON-LD 格式的结构化数据，帮助搜索引擎理解内容。
· Open Graph 标签：优化在社交媒体上的分享预览效果。
· robots.txt：创建此文件来指导搜索引擎爬虫的抓取行为。

👤 四、打造你的个人资料页（Profile SEO）

· Profile README：创建与用户名同名的仓库 (username/username)，撰写详细自我介绍，自然地使用与你技能和兴趣相关的关键词。
· 完善个人信息：填满 Bio、Company、Location、Website 等所有字段，它们被搜索引擎视作“元描述”。
· 保持活跃：定期有公开贡献（私有贡献爬虫不可见）。
· 精选仓库：在个人资料页固定（Pin）最多 6 个最能代表你的仓库。

🔗 五、站外推广与外部链接（至关重要）

· 获取外链：在个人博客、LinkedIn、Twitter、Medium 等地方链接到你的 GitHub 主页或特定仓库。外链是搜索引擎发现和评估你页面重要性的主要方式。
· 社区分享：在 Hacker News、Reddit 等相关社区分享你的项目。
· 交叉推广：在项目文档、论坛签名等地方提及你的 GitHub。

⚙️ 六、持续优化与监控

· 保持更新：定期提交代码、回应 Issue 和 PR，搜索引擎偏爱“活”的项目。
· 提高互动：优质的文档和项目体验能吸引更多 Star 和 Fork，这些“社交信号”会提升排名。
· 检查封禁：在无痕模式下打开你的 GitHub 主页，如显示 404，说明可能被误判为垃圾账户，需联系 GitHub 支持。
· 耐心等待：搜索引擎抓取和索引需要时间，优化后请耐心等待几天到几周。
